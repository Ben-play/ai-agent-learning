L25 主流 LLM API 上手 1 问
QOpenAI、Anthropic 的 SDK 长得不一样，换厂商是不是要重写一大堆代码？
A

核心心智是相通的，业务代码基本不用大改。两家都是"传一个 messages 列表、拿回一段生成"，差异集中在调用入口和少数字段名：OpenAI 是 client.chat.completions.create、Anthropic 是 client.messages.create；system 提示的位置、stop 参数名等略有不同。

生产上换厂商的标准做法是加一层网关（如 LiteLLM），用统一的 OpenAI 兼容接口把多家包在后面，切换只改配置。所以别把厂商 SDK 的调用散落到业务各处——包一个自己的薄封装，未来换厂商只动那一层。
