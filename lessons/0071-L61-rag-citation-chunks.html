第七阶段 · 数据基础与 RAG45分钟

把 PDF、HTML 和 Markdown 切成可引用的证据

人能沿引用回到准确的原文，而不是只看到一个能打开的链接

为什么切片不只是拆短文本？

值班同事问「晚班包装什么时候还？」助手回答「20:10」，附上样品退还指引的链接。新同事打开同一篇指引的第二段却看见「20:40」。链接能打开，文档号、段号也都没变，双方仍可能查到不同事实：索引里的段落来自上个版本，浏览器打开的是当前版。没有版本的引用无法解释差异；显示旧引文却把链接跳到当前页，会让人误以为新文档支持旧时间。先把引用定义清楚，比调大检索条数更能解决这类问题。

学习目标

  • 为三种来源保留文档标识、发布版本与原始定位，辨别来源不是同一个文件名或网页入口。
  • 把固定来源导入共享实验库，从授权检索的结果生成带引用的原文回答，再回查准确的页／段。
  • 验证缺失、无权和过期的引用不能回查；说清预抽取页夹具和实际 PDF 解析的区别。

1. 先为原文打坐标，再决定给检索多大一块

doc_id 是发布清单给文档分配的稳定标识，不用文件名推断两个文档是否同一份。version 是不可变的发布版；在生产中可以是发布编号或可复核的内容摘要。显示标题可改，内容也可能重排，因而引用至少需要「文档标识、版本、定位」三元组。新增版本应发布新的记录，把旧版留作可选审计资料；不能用新字节覆盖原记录却保留同一个版本号。多租户使用时，文档标识还需要处于 L60 已授权的租户或文档域中。

PDF：先保持物理页序，用 page:2 表示文件第二页，而不是页脚印的「2」。封面、序言和重新排版都会造成页标记与物理序号不一致。文本层可抽取不等于读序正确：多栏、表格、脚注和扫描页会让输出断裂或为空。若一页有好几项截止时间，仅保留页码仍可回查，但发布时还应标明准确摘录或页内位置，跨页规则则要保留两个来源位置，而不是拼完只留第一页。

HTML：示例定位到正文 main 内带原生锚点的段落，按段提取并保留 id；行号不是地址，菜单与导航也不自动成为问答资料。Markdown：本课夹具只有标题和由空行分隔的正文，忽略标题，把正文段从一开始编号；段号只对该版本有意义。真实 Markdown 有列表、表格和代码围栏，需按选定语法解析，不能拿这个空行切分器承诺通用支持。两种来源都可能变更段落或锚点，只有原始版本加定位能让后复核的人知道实际取过哪段。

本课简化为「一页或一段一个片段」。生产的检索窗可以把同一小节里的相邻段拼起来，补足「此规则仅适用于工作日」等限定语；回答引用时却应选择能支持这条声明的具体来源，不把同窗的其他段都列为证明。遇到很长一页，可分多个检索片段并保留共同页码及可选偏移；分窗或重叠是在帮召回，不应更改原文坐标。片段的内部索引编号适合去重或重排，不应作为用户回查地址。

2. 链接状态与原文证据要分别判定

检索和打开引用都使用宿主选定的租户与用户。回答展示前、再次打开时，都先用 db.source 检查该范围内是否仍能读取完全相同的「文档、版本、定位」。有权读取且摘录相同，才调用 Catalogue.resolve，按当前清单依次核对文档、版本与位置，重读原文并比对正文。无权、记录缺失、过期或原文不符，对外统一为不可用，不用诊断词泄露文档是否存在。

只在受信的合成夹具自检中单独观察清单状态：unknown_document 表示不在清单；version_mismatch 表示版本不符，即使当前位置还在也不代补；unknown_locator 表示版本匹配但位置不存在。这不是说旧版本必须删除；若业务允许读历史，可另建带访问限制的归档入口，明确标示旧版本，不能偷偷跳到当前规则。定位和原文一致也不等于它回答了问题，例如「周末单独预约」不支持「周末 18:30 停止」。本课用固定词项和原文回答验证证据回查，不评估模型或检索质量。

3. 跑清一次数据流：文件 → 授权检索 → 回答与引用 → 原文

工作台按固定清单读取三份材料：PDF 用预抽取页 JSON，HTML 提取正文带锚点的段，Markdown 给正文段编号。Catalogue.seed_rows 把各页／段的原文、版本化定位和少量固定词项转成共享 SQLite 实验库的片段；宿主同时指定每份文档的读者。db.search 先按范围过滤，再按词项匹配排序。只有第一条命中带有全部请求词项、且原文可核对，才摘录作答；这是本地标签门槛，不做语义判断。引用直接取自命中的键，不由问题或答案字符串拼出。否则不回答。L62 用独立合成语料进一步比较词法检索。

最佳实践：每个能展示的引文，都能按发布版找到出处

适用：政策、操作规程、交接通知等会变更且需要回查的材料。边界：没有版本凭据或稳定锚点时，只能声明定位粒度与限制，不能从今天的页面补造昨天的坐标。

仅保存浏览入口

命中时只保留 URL 或检索片段编号；网页换版后，点开正常、引用却可能支持另一套规则。

分开检索键与回查键

索引保存片段及版本化定位，展示时用清单回查，摘录与声明一起校验。旧版不可用时显式拒绝，不重写版号。

权衡：版本清单、锚点与索引要一起发布，重算与保留成本增加；复核者因此能区分材料更新、定位失败和答案误读。

  1. 抽取前确定文档身份及版本，按页或段建坐标；再设计检索窗大小。
  2. 对同一定位测试旧版与当前版，再用一条确实不存在的定位拆开错误原因。

诊断：版号一致却找不到，先查抽取和定位；同段号的旧引用竟被接受，先查键是否包含版号；链接与内容都正确却结论不对，检查声明是否超出原文。

Q 一条待发布回答的旧引文说 20:10。当前版仍有第 2 段，但已改成 20:40；另有可核对的独立领取时间。业务只展示当前规则，旧版归档仍可打开。发布前怎么处理？
历史归档适合解释旧决策，不能证明当前时间；改链接不等于重核结论。领取证据仍然有效，但不能替代归还证据。只有重取当前归还片段并重新判读，才能同时保留两个正确、独立的结论。

import runpy
from dataclasses import replace

if not __debug__:
    raise RuntimeError("run without -O")
lab = runpy.run_path("code/phase7-data-rag/rag-lab/foundations/citations.py")
Citation, Chunk, Resolution = (lab[name] for name in ("Citation", "Chunk", "Resolution"))
Scope, Query = lab["HostScope"], lab["Query"]
answer, reopen = lab["answer"], lab["reopen"]
catalogue = lab["Catalogue"]("desk", lab["WORKED_CURRENT"])
lin, mei = Scope("desk", "lin"), Scope("desk", "mei")
grants = {"dispatch": ("lin",), "office": ("mei",), "guide": ("lin",)}
office_query = Query(("周三", "纸质登记"))
unavailable = Resolution("unavailable")
with lab["open_demo"](rows=catalogue.seed_rows(grants)) as db:
    for scope, query, citation, filename, quote in (
        (lin, Query(("cold-room", "weekday")), Citation("dispatch", 2, "page:2"),
         "dispatch-v2.pdf",
         "Cold-room pickup closes at 18:30 on weekdays.\nWeekend pickup requires a separate booking."),
        (mei, office_query, Citation("office", 4, "paragraph:counter"),
         "office-v4.html", "周三的纸质登记由西门窗口受理。"),
        (lin, Query(("蓝色标签",)), Citation("guide", 1, "paragraph:1"),
         "guide-v1.md", "蓝色标签用于当天归还的样品柜。"),
    ):
        reply = answer(db, catalogue, scope, query)
        assert (reply.citation, reply.text) == (citation, quote)
        assert reopen(db, catalogue, scope, reply) == Resolution("ok", Chunk(citation, quote), filename)

    office = answer(db, catalogue, mei, office_query)
    assert reopen(db, catalogue, lin, office) == unavailable
    assert reopen(db, catalogue, Scope("other-desk", "mei"), office) == unavailable
    assert db.source(lin.tenant, lin.user, office.citation.key) is None
    assert reopen(db, catalogue, lin, replace(office, scope=lin)) == unavailable
    partial_match = Query(("蓝色标签", "无此词项"))
    assert db.search(lin.tenant, lin.user, partial_match, k=1)[0].chunk.key == ("guide", 1, "paragraph:1")
    for query in (office_query, Query(("无此词项",)), partial_match):
        assert answer(db, catalogue, lin, query) == lab["Answer"](lin, lab["NO_EVIDENCE"])
    missing = Citation("office", 4, "paragraph:missing")
    assert reopen(db, catalogue, mei, replace(office, citation=missing)) == unavailable
    assert reopen(db, catalogue, mei, replace(office, text="摘录不一致")) == unavailable
    db.revoke(mei.tenant, mei.user, "office")
    assert reopen(db, catalogue, mei, office) == unavailable

# 清单诊断只用于可信的本地自检，不是公开的引用接口。
assert catalogue.resolve(missing) == Resolution("unknown_locator")
assert catalogue.resolve(Citation("missing", 1, "page:1")) == Resolution("unknown_document")

# 同键但正文失配的索引不可生成回答，即使 SQLite 仍授权这条记录。
rows = ((tenant, replace(chunk, text="索引正文失配"), users)
        for tenant, chunk, users in catalogue.seed_rows(grants)
        if chunk.key == office.citation.key)
with lab["open_demo"](rows=rows) as db:
    assert db.search(mei.tenant, mei.user, office_query)[0].chunk.text == "索引正文失配"
    assert answer(db, catalogue, mei, office_query) == lab["Answer"](mei, lab["NO_EVIDENCE"])

import runpy
from dataclasses import replace

if not __debug__:
    raise RuntimeError("run without -O")
lab = runpy.run_path("code/phase7-data-rag/rag-lab/foundations/citations.py")
Citation, Chunk, Resolution = (lab[name] for name in ("Citation", "Chunk", "Resolution"))
answer, reopen, Query = lab["answer"], lab["reopen"], lab["Query"]
scope = lab["HostScope"]("samples", "ren")
previous = lab["Catalogue"](scope.tenant, lab["TRANSFER_INITIAL"])
current = lab["Catalogue"](scope.tenant, lab["TRANSFER_CURRENT"])
grants = {"returns": ("ren",), "pickup": ("ren",)}
returns_query, pickup_query = Query(("晚班", "归还")), Query(("领取台", "发放标签"))
appendix_query = Query(("附录",))
unavailable = Resolution("unavailable")
with lab["open_demo"](rows=previous.seed_rows(grants)) as db:
    old = answer(db, previous, scope, returns_query)
    appendix = answer(db, previous, scope, appendix_query)
    pickup = answer(db, previous, scope, pickup_query)
    assert (old.citation, old.text) == (
        Citation("returns", 3, "paragraph:2"), "晚班包装须在 20:10 前归还；逾时登记到下一班。")
    assert (appendix.citation, appendix.text) == (
        Citation("returns", 3, "paragraph:3"), "旧版附录：纸质登记由后门桌收取。")
    assert reopen(db, previous, scope, old).chunk == Chunk(old.citation, old.text)
    assert reopen(db, previous, scope, appendix).chunk == Chunk(appendix.citation, appendix.text)
    assert reopen(db, current, scope, old) == unavailable  # 清单领先于索引也不放行。

    db.replace_document(scope.tenant, "returns", 4, lab["index_chunks"]("returns", 4))
    assert reopen(db, current, scope, old) == unavailable
    assert reopen(db, previous, scope, old) == unavailable  # 旧清单也不能绕过当前索引。
    assert reopen(db, current, scope, appendix) == unavailable
    assert reopen(db, current, scope, replace(appendix, citation=Citation("returns", 4, "paragraph:3"))) == unavailable
    assert answer(db, current, scope, appendix_query).citation is None
    assert answer(db, previous, scope, returns_query).citation is None

    fresh = answer(db, current, scope, returns_query)
    assert (fresh.citation, fresh.text) == (
        Citation("returns", 4, "paragraph:2"), "晚班包装须在 20:40 前归还；逾时登记到下一班。")
    assert reopen(db, current, scope, fresh) == Resolution("ok", Chunk(fresh.citation, fresh.text), "returns-v4.md")
    assert reopen(db, current, scope, replace(old, citation=fresh.citation)) == unavailable
    assert (pickup.citation, pickup.text) == (
        Citation("pickup", 1, "paragraph:2"), "晚班领取台在 19:45 停止发放标签。")
    assert reopen(db, current, scope, pickup) == Resolution("ok", Chunk(pickup.citation, pickup.text), "pickup-v1.md")

# 错误对照：当前版同段号确实能打开，但不是旧回答引用的版本和正文。
assert old.citation.locator == fresh.citation.locator and old.text != fresh.text
assert current.resolve(old.citation) == Resolution("version_mismatch")
assert current.resolve(Citation("returns", 4, "paragraph:3")) == Resolution("unknown_locator")
print("L61 TRANSFER PASSED")

面试自查

回答时先说你会保留哪些证据，再说哪条测试能区分两个相似故障。

Q1切片已经有唯一编号，为什么仍需要文档和版本定位？

参考回答：片段号依赖索引构建，换窗口规则或重建后可能改变。用户回查要知道来自哪份文档的哪次发布和哪一页或段；多片段也可以共享同一来源位置。

追问：同一份 PDF 分两种片段长度，引用坐标应随之变化吗？

答题要点：文档版本、物理页等原始坐标不变；检索编号可变，摘录范围可更精确，但不能失去原始坐标。

Q2同样的页码或锚点还能打开，为什么要判可能过期？

参考回答：相同定位在不同版上可对应不同内容。先判版本，再找该版定位；只准当前内容时对旧版显式拒绝，重新取证后重核结论。

追问：如果业务需要历史证据呢？

答题要点：有权限时按指定旧版从不可变归档读取，清楚标记历史，不自动跳转最新版，也不把版号改成当前。

Q3页 JSON 全部测试通过，可以宣称 PDF 支持完成吗？

参考回答：不可以。JSON 测试从已定位的页文本开始；单独抽取一个简单文本 PDF 也只证明这一文件的文本抽取。扫描件和复杂读序还需独立验收。

追问：扫描页抽取为空，直接跳过再重新编号可以吗？

答题要点：不应挪动后续物理页号。保留缺页状态，按需求单独走 OCR 或人工复核，不能把空页当没有相关规则。

Q4引用解析成功就说明生成答案可靠吗？

参考回答：成功只说明指定版本和定位可回查。还要查看该摘录是否支持问题对应的条件与结论。例如工作日的截止时间不能直接当周末规则。

追问：缓存命中后用户刚失去阅读权限怎么办？

答题要点：先在可信宿主上重验权限或清缓存，不能因为曾能回查就继续返回；版本完整与获准访问均是独立门槛。
