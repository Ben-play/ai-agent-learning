阶段 2 · AI 知识与模型选型

从"调 API 的人"升级为"懂 LLM 的人"——看透模型的本质、局限、选型与成本，覆盖 9+ 道面试高频题。

📚 共 3 个模块 · 8 课 ⏱ 深度学习约 430 分钟
阶段实践边学边做：本阶段含 11 张知识点决策卡、8 个单课近迁移验收，以及 5 个跨课检查点。检查点在最后一个先修知识学完后立即出现：L18 请求契约、L19 可靠性门、L21 能力策略、L22 私有评测、L23 成本感知路由。完成 L24 后，再打开 Phase 2 阶段复盘索引并运行离线模型评测综合项目；复盘页不计为新课。
为什么 Phase 1 之后先学这个？
你已经能写健壮的 Python 了，但在真正搭 Agent 前，必须先看透手里这个 LLM 到底是什么：
· 不懂"概率预测"本质 → 调 temperature/top_p 只能靠玄学，还会误以为它在"检索事实"
· 不懂 Token → 算错成本、爆掉上下文窗口、被"中文更费钱"的谣言误导
· 不懂幻觉的成因 → 上线后被"一本正经胡说八道"反复打脸，不知道怎么治
· 不会选型/算成本 → 要么全用最贵的模型烧钱，要么用错模型质量不达标
先看懂模型，再驾驭模型。本阶段每一课都直接对应一道面试必答题。

Module 2.1 · LLM 本质与核心概念

抛开神秘感，把 LLM 拆成"下一个 Token 预测机"，并掌握你每天都在设的旋钮。

2.1

本质、Token 与生成参数

L1745min
LLM 本质与生成参数 AI 面试
语言模型本质、注意力与生成直觉；区分 Temperature / Top-P / 重复惩罚的解码概念与厂商 API 字段——部分新 Claude 模型会拒绝 sampling 控制的非默认值；理解低温/seed 也不能保证逐字节复现
为抽取、创作、代码审查选择控制方式：支持 sampling 的 provider 如何调参，当前 Claude 如何用提示约束、结构化校验与 effort
L1860min
Token 与 Tokenization 深入 AI 面试
Token 是子词片段；BPE 是常见 tokenizer 家族而非唯一实现；中文/英文效率取决于目标 tokenizer；tiktoken 对匹配 OpenAI 编码计数，Claude 用官方 messages.count_tokens 估算并以 response usage 对账
对同一段 system prompt：用 tiktoken 比较 cl100k/o200k，再说明 Claude 为什么必须改用自己的 count-tokens 端点

Module 2.2 · 模型能力、局限与选型 面试重灾区

模型能做什么、做不到什么、怎么在几十个模型里选对——资深面试的核心战场。

2.2

幻觉、推理模型与能力边界

L1955min
幻觉全解（多因素视角） AI 面试
什么是幻觉；两层重要机制（预训练统计错误如何产生、评估为何鼓励猜测）与其他工程成因；Self-Consistency 发散只作风险信号，一致不证明正确；RAG / 引用 / 工具 / 人工组合兜底
为一个客服 Agent 设计幻觉检测方案——用多次采样一致性 + 要求引用来源，标注哪些回答高风险
L2045min
推理能力与 Adaptive Thinking AI 面试
区分模型推理能力、Adaptive Thinking 与 effort；当前 Claude 用 thinking: adaptive + output_config.effort，固定 budget_tokens 仅属旧模型兼容；理解 display、计费、max_tokens 与 overthinking 边界
给抽取、数学、合同分析和规划任务选择起始模型/effort，并写出质量、延迟、Token 与外部核验指标
L2160min
模型能力边界与 Base vs Instruct AI 面试
Base/Instruct 的行为倾向；预训练、SFT 与偏好优化（RLHF/DPO 类路线）；微调与 RAG 的边界；区分直接文档输入、RAG、实时工具；API 默认无状态不等于应用不能保存记忆
为股价、计算、跨会话偏好和上传 PDF 分别选择当前上下文、业务工具、应用状态或 RAG，说明为什么不能统一套一种方案
L2260min
看懂 Benchmark 与模型选型 AI 面试
主流 benchmark 各测什么；污染、针对性优化、场景不匹配、harness/scaffold/预算如何影响成绩；开放权重、托管与自托管边界；开发集/隔离测试集、固定 rubric 与重复运行
为敏感合同 Agent 先写可审计合规硬约束，再用隔离评测集和真实负载比较合规托管、开放权重托管或自托管候选

Module 2.3 · Token 经济学

生产级 Agent 的必修课——把成本从"随便烧"变成"精打细算"，并综合实战收官。

2.3

成本工程与综合实战

L2360min
Token 经济学与降本杠杆 AI 面试
请求历史与累计成本、Token 预算；Prompt Caching 的 5m/1h 写入、读取、盈亏平衡、最小前缀和 usage；Model Routing 的误路由/升级成本；案例百分比不作保证；厂商 Batch、压缩和输出控制边界
给定"2000 token 固定 system prompt + 每次 200 token 问题 + 300 token 回答、日 10 万次"，算不加缓存的日成本，再算 Prompt Caching 能省下哪部分、大致多少
L2445min
Phase 2 综合实战项目 综合
收官项目「模型体检报告」：各厂商计数方式 + Provider Adapter + async 并发；离线 mock 覆盖一致/部分一致/发散；ground truth 区分稳定性与事实错误；指标归一化后再加权
离线跑通模型矩阵、三种一致性分支、成本数学与归一化选型；真实 Claude 接口使用官方 Anthropic SDK adapter

学习建议

Module 2.1 打底——LLM 本质 + Token 是后面一切的地基，务必用 tiktoken 亲手数一遍，建立"Token=钱"的体感。
Module 2.2 是面试重灾区——幻觉成因（校准视角）、推理模型何时用、六大能力局限、benchmark 判读 + 选型框架，每一条都是资深岗必问。别死记结论，理解"为什么"。
Module 2.3 收尾——成本工程是生产级思维的起点（Phase 3 起会一直用“先测量，再验证缓存与路由”），最后用 L24 把整个 Phase 2 串成一个能跑的项目。
实践顺序——每张卡先读决策与边界，单课验收和阶段检查点都先独立实现、再展开参考程序；全部课程结束后才用复盘页压缩主题并完成最终项目。
