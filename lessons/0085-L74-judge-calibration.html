评委校准与人工金标

先测评委会在哪里判错，再决定它能辅助哪些判断

评委给了高分，为什么还不能发布？

一句「同步每日凌晨两点」与「同步任务每天 02:00 运行」在本题口径下等价，简单字符串比较会错杀；一句「导出留存一周」则虽然忠实，却没有回答同步问题。开放文本值得另外评分，但评委不能给错定位、越权引用或未授权写入开绿灯。

学习目标

  • 能说清哪些确定性核验必须阻断、哪些语义差异应交给评委。
  • 能分轴重算混淆表、覆盖率和未决率，并解释一次错放。
  • 能用调用计数证明等价改写进入评委，而错误引用不会触发调用。

1. 先定口径，再各自标注

把问题与实际材料一起冻结：在交班卡中，导出文件生成后保留七天，同步任务每天凌晨两点运行。忠实度（support）问「候选写出的事实是否都能由本轮材料支持」；完整性（completeness）问「本题两处需要回答的槽位是否都给出了明确值」。本课的完整性只看有没有覆盖，不替数字纠错，因此可出现「填齐但有错」；反过来只正确答第一问，忠实度通过但完整性失败。这个区别使错字、漏项、语义改写和无依据新增能分别诊断，而不是靠一个总分猜测模型该怎么改。

课程作者逐行标注合成答复，把标签和理由写进 evaluation/fixtures/v1/judge-gold.json；另有手写的模拟评委输出 judge-mock.json，故意含误判与弃权，不是模型实测。真实评委的校准应让两位标注人独立读同一问题和证据，先不看评委、另一位标注人或候选版本；记录分歧，由指定复核人按冻结口径裁决，无法裁决则保留理由并标为 uncertain。不要删除难行，也不要为了让评委更一致而静默重写金标。本实验没有第二位标注人或生产抽样，不从演示数字推断人评一致性。

judge_qa 与 L73 的结构化评分共用确定性出处门：实际包及每条引用都必须属于当前可读、版本和段落精确、整段原文一致的材料，每个引用还必须在本轮包内。硬门不比较候选值与人工金标，也不把金标的答复形状当成硬门。通过后才把问题、请求槽位、证据包和候选答复交给确定性评委桩，不传标签、题号、数据分区或数据库。这个桩只识别少量本课词形，例如把「一周」和「每天凌晨两点」对照包内原文；它既不是通用语义判断，也不同于下面用于校准统计的固定模拟票。

两份表按稳定编号连接，禁止靠行顺序配对；编号缺失、重复、口径版本不一致或标签表外值都应尽早暴露。候选评委不读人工金标。若未来选用真实模型，另行冻结模型标识、提示或评分表版本及推理设置；只给最小可用证据。记录模型拒答、格式错误及无把握时的处理，避免它们被当作默认通过。用未参与提示调整的样本再验一次；还可以打乱结果展示顺序、控制答复长短并比较不同候选来源，查长度与自偏好。这一课完全离线，不调用任何真实评委。小样本最多揭示故障类型；自动放行阈值应在足够覆盖错误代价的样本上另订，而不是从这八条推算。

把 pass 当正类，只把人工已裁决且评委已投二元票的行放进混淆表：真通过是 TP，真失败是 TN；错放不合格为 FP，错拦合格为 FN。CAL-02 在忠实度是 FN、在完整性是 FP，正因它没编造但漏答。CAL-03 的忠实度 FP 尤其值得复核，因为它会把不实业务事实放行。金标 uncertain 与评委 abstain 是不同来源：两者可落在同一行，弃权的行也不能默认记成失败、成功或分歧。公布各自样本编号和分母，能防止评委靠对难题全弃权来美化一致率。

  • 设总行数为 N，金标已决数 K = N − 人工不确定数，可比较数 D = TP + TN + FP + FN。
  • 覆盖率 D / K；条件一致率 (TP + TN) / D；条件分歧率 (FP + FN) / D。分母为零时报告未定义，不报零或百分之百。
  • 人工不确定率 人工不确定数 / N；评委弃权率 全部评委弃权数 / N，另列已决行内哪些被弃权。

决策卡：硬门槛优先，软分只补空白

适用：开放措辞有合理改写，精确引用与权限仍可用代码判定。边界：没有生产质量证明，不用模拟票决定上线。

误判：均分高就放行

在总分里藏掉错放、漏项、弃权；用模型票覆盖硬规则。

选择：逐轴校准与人工复核

金标和预测分别冻结；硬失败直接阻断，语义不确定转人工。

代价：分轴标注、复核错放和接手弃权都耗费人力；只在硬门过后调用，避免在注定失败的样本上花费评分预算。

  1. 先核对授权、引用和允许的终态；硬失败不调用评委。
  2. 对已通过硬门的候选分别看忠实和完整，按编号联接校准表。
  3. 派人复核错放与弃权，修改评分表后用未调参的样本重新校准。

诊断：一致率升高而覆盖下降，先复查弃权是否偏向难例；两轴在同一行相反，先看判据是否被合并，而不是先改阈值。

Q 金标对忠实度不确定，评委给通过；若该候选的引用定位也未过硬检查，应如何记账？
人工不确定不是二元标签；确定性失败不允许被投票覆盖。

面试自查

Q1 客服答「导出留七天」却没说同步时间，两轴怎么判？

参考回答：本题忠实度通过，完整性失败，因为仅覆盖一问，但写出的事实受证据支持。

追问：若填齐问题，却把七天改成三十天？

答题要点：本题槽位覆盖仍通过，忠实度失败；业务发布不能把两者平均后放行。

Q2 评委一致率提高，但弃权从一成变成一半，怎么汇报？

参考回答：同时汇报已决覆盖和总弃权率、混淆格及变化的样本类别。挑容易的行回答可以抬高条件一致率。

追问：是否把所有弃权记为错判就行？

答题要点：不应混淆投错票和没有票。可以另外统计含弃权的流程成本，但保留原始状态和分母。

Q3 人工标注争论「按交接班时区」是否受支持，应该移除该行吗？

参考回答：保留该行和争议理由，按口径复核。无法裁决就记 uncertain，不纳入二元混淆格。

追问：补充时区政策后怎么办？

答题要点：更新并冻结证据与金标版本，再重新标注和评估，不与旧分母直接合并。

Q4 两个评委都认为答案有理，但机器发现错引或未授权写入，能投票通过吗？

参考回答：不能。确定性失败直接阻断，不是和开放评分相加的扣分项。

追问：如果硬门通过、评委却弃权？

答题要点：标为待人工复核，记录题号和原因；不要把弃权当通过。
