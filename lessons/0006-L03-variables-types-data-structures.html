1. 变量：标签，不是盒子

很多初学者把变量想象成"盒子"，值装在盒子里。这是错的。

Python 变量是标签（引用），贴在对象上：

a = [1, 2, 3]
b = a          # b 和 a 指向同一个列表对象
b.append(4)
print(a)       # [1, 2, 3, 4]  ← a 也变了！

内存模型：

a ──→ [1, 2, 3, 4] ←── b
      （同一个对象）
🔑 Agent 开发关联：

LLM 返回的 response 对象经常被多个变量引用。如果你修改了一个引用的数据，其他引用也会受影响。这是 Agent 开发中常见的 bug 来源。

Q 下面代码的输出是什么？ 
x = [1, 2]
y = x
y = y + [3]
print(x)
y = y + [3] 创建了一个新列表对象，y 重新指向新对象。x 仍然指向原来的 [1, 2]。
如果是 y.append(3)，那 x 就会变了。

2. 可变与不可变类型

Python 的数据类型分为两大阵营：

不可变（Immutable） 可变（Mutable）
int float str bool
tuple frozenset		 list dict set
值不能修改，修改会创建新对象 值可以原地修改

不可变类型的"陷阱"

s = "hello"
s[0] = "H"    # ❌ TypeError: 'str' 不支持 item assignment

# 正确做法：创建新字符串
s = "H" + s[1:]  # "Hello"

可变类型作为默认参数的陷阱

def add_item(item, lst=[]):    # ⚠️ 危险！
    lst.append(item)
    return lst

print(add_item("a"))  # ["a"]
print(add_item("b"))  # ["a", "b"]  ← 不是 ["b"]！

原因：默认参数 [] 只在函数定义时创建一次，之后每次调用共享同一个列表对象。

# 正确做法
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst
🔑 Agent 开发关联：

Agent 的工具函数经常有默认参数。如果用了可变默认参数，会导致多次调用间状态串扰。这是 Agent 测试中最难发现的 bug 之一。

Q 下面哪个对象可以作为 dict 的 key？
dict 的 key 必须是 hashable 的，即不可变且可哈希。tuple 是不可变的，可以当 key。list、dict、set 都是可变的，不行。 注意：包含可变元素的 tuple（如 (1, [2, 3])）也不行。

3. 引用计数与垃圾回收

Python 用引用计数管理内存。每个对象有一个计数器，记录有多少变量指向它：

import sys

a = [1, 2, 3]
print(sys.getrefcount(a))  # 2（a 本身 + getrefcount 的参数）

b = a
print(sys.getrefcount(a))  # 3

del b
print(sys.getrefcount(a))  # 2

当引用计数降为 0，对象被立即回收。

💡 面试常见问题：

"Python 的垃圾回收机制是什么？"

答：主要靠引用计数，辅以分代回收处理循环引用。不可变对象（int/str）有缓存池优化。

4. 四大容器：list / dict / tuple / set

list — 有序、可变、可重复

# 创建
tools = ["search", "calculator", "weather"]

# 常用操作
tools.append("file_reader")     # 末尾添加
tools.insert(0, "planner")      # 指定位置插入
tools.pop()                     # 移除末尾并返回
tools.remove("calculator")      # 按值删除
tools.sort()                    # 原地排序
len(tools)                      # 长度

# 切片（Agent 开发中用于截取对话历史）
messages = ["msg1", "msg2", "msg3", "msg4", "msg5"]
recent = messages[-3:]          # 最近 3 条消息
except_last = messages[:-1]     # 除最后一条外的所有消息

dict — 键值对、有序（Python 3.7+）、可变

# 创建（Agent 的核心数据结构）
config = {
    "model": "gpt-4",
    "temperature": 0.7,
    "max_tokens": 1000
}

# 访问
config["model"]                 # "gpt-4"
config.get("timeout", 30)      # 带默认值的安全访问

# 修改
config["temperature"] = 0.5     # 修改
config["stream"] = True         # 新增

# 遍历
for key, value in config.items():
    print(f"{key}: {value}")

# 字典推导式
tools = {"search": 10, "calc": 5, "weather": 8}
limited = {k: min(v, 8) for k, v in tools.items()}
# {"search": 8, "calc": 5, "weather": 8}

tuple — 有序、不可变、可重复

# Agent 中用于不可变的配置
POINT = (39.9, 116.4)           # 北京坐标
API_VERSION = ("v1", "stable")

# 解包
x, y = POINT
name, version = API_VERSION

# tuple 的不可变性保护数据不被意外修改
# 适合用作 dict 的 key
locations = {
    (39.9, 116.4): "北京",
    (31.2, 121.5): "上海"
}

set — 无序、不可重复

# 去重（Agent 中用于去除重复工具调用）
calls = ["search", "calc", "search", "weather", "calc"]
unique_calls = set(calls)       # {"search", "calc", "weather"}

# 集合运算
allowed = {"search", "calc", "weather", "file"}
requested = {"search", "hack", "weather"}
blocked = requested - allowed   # {"hack"}
approved = requested & allowed  # {"search", "weather"}

Agent 系统中最常用的容器：

  • dict：配置、LLM 响应、工具参数 — 几乎无处不在
  • list：对话历史、工具列表、批量结果
  • tuple：不可变的元组数据（坐标、版本号）

5. 推导式：Python 的数据转换利器

推导式是 Python 最强大的语法特性之一，Agent 开发中大量使用。

列表推导式

# 传统写法
results = []
for tool in tools:
    if tool["enabled"]:
        results.append(tool["name"])

# 推导式（一行搞定）
results = [tool["name"] for tool in tools if tool["enabled"]]

# 带条件转换
statuses = ["success", "error", "success", "pending"]
icons = ["✅" if s == "success" else "❌" for s in statuses]
# ["✅", "❌", "✅", "⏳"]

字典推导式

# 从 LLM 响应中提取工具调用
response = {
    "tool_calls": [
        {"name": "search", "args": {"q": "python"}},
        {"name": "calc", "args": {"expr": "1+1"}}
    ]
}

# 提取工具名和参数
tool_map = {tc["name"]: tc["args"] for tc in response["tool_calls"]}
# {"search": {"q": "python"}, "calc": {"expr": "1+1"}}

集合推导式

# 提取所有唯一工具名
all_calls = ["search", "calc", "search", "weather"]
unique = {call for call in all_calls}
# {"search", "calc", "weather"}

嵌套推导式（谨慎使用）

# 扁平化嵌套列表
nested = [[1, 2], [3, 4], [5, 6]]
flat = [x for sublist in nested for x in sublist]
# [1, 2, 3, 4, 5, 6]

6. dict 深度操作

嵌套访问：安全取值

# LLM 响应通常有多层嵌套
response = {
    "choices": [{
        "message": {
            "tool_calls": [{
                "function": {
                    "name": "search",
                    "arguments": '{"q": "python"}'
                }
            }]
        }
    }]
}

# ❌ 危险的写法（任何一层缺失就报错）
name = response["choices"][0]["message"]["tool_calls"][0]["function"]["name"]

# ✅ 安全的写法（封装为函数）
def safe_get(d, *keys, default=None):
    for key in keys:
        if isinstance(d, dict):
            d = d.get(key, default)
        elif isinstance(d, list) and isinstance(key, int):
            d = d[key] if 0 <= key < len(d) else default
        else:
            return default
    return d

name = safe_get(response, "choices", 0, "message", "tool_calls", 0, "function", "name")

defaultdict：自动创建默认值

from collections import defaultdict

# 统计工具调用次数
call_count = defaultdict(int)    # 默认值为 0
calls = ["search", "calc", "search", "weather", "search"]
for call in calls:
    call_count[call] += 1
# {"search": 3, "calc": 1, "weather": 1}

# 按类型分组工具
tools_by_type = defaultdict(list)  # 默认值为 []
tools = [
    {"name": "search", "type": "web"},
    {"name": "calc", "type": "math"},
    {"name": "weather", "type": "web"},
]
for tool in tools:
    tools_by_type[tool["type"]].append(tool["name"])
# {"web": ["search", "weather"], "math": ["calc"]}

ChainMap：合并多个字典

from collections import ChainMap

# Agent 配置的优先级合并
user_config = {"model": "gpt-4", "temperature": 0.9}
project_config = {"model": "gpt-3.5", "max_tokens": 500}
default_config = {"model": "gpt-3.5", "temperature": 0.7, "max_tokens": 1000}

# user > project > default
config = ChainMap(user_config, project_config, default_config)
print(config["model"])        # "gpt-4"（user 优先）
print(config["temperature"])  # 0.9（user 优先）
print(config["max_tokens"])   # 500（project 优先）

其他常用 dict 方法

# setdefault：获取值，不存在则设置默认值
cache = {}
result = cache.setdefault("key_123", compute_expensive())
# 等价于：
if "key_123" not in cache:
    cache["key_123"] = compute_expensive()
result = cache["key_123"]

# update：合并字典
base = {"model": "gpt-4", "temperature": 0.7}
override = {"temperature": 0.9, "stream": True}
base.update(override)  # {"model": "gpt-4", "temperature": 0.9, "stream": True}

# dict | 运算符（Python 3.9+）
merged = base | override  # 创建新字典，不修改原字典

# Counter：计数器（Agent 中统计 token、工具调用）
from collections import Counter
words = ["hello", "world", "hello", "python", "hello"]
word_count = Counter(words)
print(word_count.most_common(2))  # [("hello", 3), ("world", 1)]

LLM 响应是嵌套 dict，Agent 配置有多层优先级，工具参数需要安全访问 — 这些都是 Agent 开发的日常。掌握 dict 深度操作是基本功。

面试常见问题

Q1：Python 可变类型和不可变类型的区别？

答：不可变类型（int/str/tuple）的值不能修改，修改会创建新对象。可变类型（list/dict/set）可以原地修改。不可变类型可以作为 dict 的 key，可变类型不行。

Q2：Python dict 的底层实现是什么？

答：哈希表（Hash Table）。通过 key 的 hash 值定位存储位置，查找时间复杂度 O(1)。Python 3.7+ dict 保持插入顺序，是因为底层额外维护了一个链表。

Q3：tuple 和 list 的区别？什么时候用 tuple？

答：tuple 不可变，list 可变。tuple 可以作为 dict 的 key，list 不行。tuple 比 list 更省内存。用 tuple 的场景：数据不应被修改时（坐标、RGB 颜色）、需要作为 dict key 时。

Q4：defaultdict 和普通 dict 有什么区别？

答：defaultdict 在访问不存在的 key 时，会自动创建默认值（由构造参数指定），而不是抛出 KeyError。常用于计数和分组场景。

Q5：什么是可变默认参数陷阱？怎么避免？

答：函数的默认参数如果是可变对象（如 list/dict），会在函数定义时创建一次，之后每次调用共享同一个对象。避免方法：用 None 作为默认值，在函数体内创建新对象。

Q6：isinstance 和 type 的区别？

答：isinstance 支持继承关系检查（子类也返回 True），type 精确匹配类型。一般推荐用 isinstance，更符合多态设计。
