1. 变量：标签，不是盒子

很多初学者把变量想象成"盒子"，值装在盒子里。这是错的。

Python 变量是标签（引用），贴在对象上：

a = [1, 2, 3]
b = a          # b 和 a 指向同一个列表对象
b.append(4)
print(a)       # [1, 2, 3, 4]  ← a 也变了！

内存模型：

a ──→ [1, 2, 3, 4] ←── b
      （同一个对象）
🔑 Agent 开发关联：

LLM 返回的 response 对象经常被多个变量引用。如果你修改了一个引用的数据，其他引用也会受影响。这是 Agent 开发中常见的 bug 来源。

Q 下面代码的输出是什么？ 
x = [1, 2]
y = x
y = y + [3]
print(x)
y = y + [3] 创建了一个新列表对象，y 重新指向新对象。x 仍然指向原来的 [1, 2]。
如果是 y.append(3)，那 x 就会变了。

2. 可变与不可变类型

上一节看到：多个变量可以指向同一个对象。那么改动这个对象，会不会"牵连"其他变量？答案取决于这个对象能不能被改——这就引出了 Python 类型的一条根本分界：可变 vs 不可变。

Python 的数据类型分为两大阵营：

不可变（Immutable） 可变（Mutable）
int float str bool
tuple frozenset		 list dict set
值不能修改，修改会创建新对象 值可以原地修改

不可变类型的"陷阱"

s = "hello"
s[0] = "H"    # ❌ TypeError: 'str' 不支持 item assignment

# 正确做法：创建新字符串
s = "H" + s[1:]  # "Hello"

可变类型作为默认参数的陷阱

def add_item(item, lst=[]):    # ⚠️ 危险！
    lst.append(item)
    return lst

print(add_item("a"))  # ["a"]
print(add_item("b"))  # ["a", "b"]  ← 不是 ["b"]！

原因：默认参数 [] 只在函数定义时创建一次，之后每次调用共享同一个列表对象。

# 正确做法
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst
🔑 Agent 开发关联：

Agent 的工具函数经常有默认参数。如果用了可变默认参数，会导致多次调用间状态串扰。这是 Agent 测试中最难发现的 bug 之一。

Q def f(item, lst=[]) 这样写，反复调用会怎样？
默认参数 [] 只在函数定义时创建一次，之后每次调用都共享同一个列表对象——上一次 append 进去的元素会"残留"到下一次。这就是"可变默认参数陷阱"。正确做法：默认值用 None，在函数体里再 lst = []。

3. 引用计数与垃圾回收

Python 用引用计数管理内存。每个对象有一个计数器，记录有多少变量指向它：

import sys

a = [1, 2, 3]
print(sys.getrefcount(a))  # 2（a 本身 + getrefcount 的参数）

b = a
print(sys.getrefcount(a))  # 3

del b
print(sys.getrefcount(a))  # 2

当引用计数降为 0，对象被立即回收。

💡 面试常见问题：

"Python 的垃圾回收机制是什么？"

答：主要靠引用计数，辅以分代回收处理循环引用。不可变对象（int/str）有缓存池优化。

4. 四大容器：list / dict / tuple / set

前面三节讲的是"单个值"的性质（引用、可变性、回收）。但 Agent 代码里的数据几乎都是成组的——一串工具、一组消息、一份配置。Python 用四种容器来装它们，各有各的取舍：list（有序可变）、dict（键值查找）、tuple（不可变、能当 key）、set（去重）。前面学的"可变/不可变"正好解释了它们的区别。

先学会一眼区分：怎么创建、括号长什么样

四种容器最容易让初学者懵的，是它们的字面量括号很像——尤其 {} 到底是 dict 还是 set？下面这张表一次看清「怎么写出来、靠什么认出来」：

容器字面量写法一眼认出的特征有序?可变?可重复?
list[1, 2, 3]方括号 []✅✅✅
tuple(1, 2, 3)圆括号 ()（认逗号）✅❌✅
dict{"a": 1, "b": 2}花括号 + 冒号 键:值✅✅key 不可重复
set{1, 2, 3}花括号、无冒号、只有值❌✅❌

区分口诀：看括号 → [] 是 list、() 是 tuple；花括号 {} 再看里面——有冒号 : 是 dict，没冒号只有值是 set。

# 除了字面量，也能用「构造函数名」创建（还能做类型转换，见第 7 节）
list("abc")        # ['a', 'b', 'c']
tuple([1, 2])      # (1, 2)
dict(a=1, b=2)     # {'a': 1, 'b': 2}
set([1, 1, 2])     # {1, 2}   ← 顺带去重
⚠️ 两个必踩的坑（初学者 90% 会中）：
  • {} 是空 dict，不是空 set！空集合只能写 set()。因为花括号被 dict 占了，Python 没法从空 {} 分辨你要哪个，默认给 dict。
    type({}) → dict；type(set()) → set。
  • 单元素 tuple 必须带逗号：(1,)。(1) 只是"加了括号的数字 1"，类型是 int——是逗号而非括号造就了 tuple。
    type((1)) → int；type((1,)) → tuple。

list — 有序、可变、可重复

# 创建
tools = ["search", "calculator", "weather"]

# 常用操作
tools.append("file_reader")     # 末尾添加
tools.insert(0, "planner")      # 指定位置插入
tools.pop()                     # 移除末尾并返回
tools.remove("calculator")      # 按值删除
tools.sort()                    # 原地排序
len(tools)                      # 长度

# 切片（Agent 开发中用于截取对话历史）
messages = ["msg1", "msg2", "msg3", "msg4", "msg5"]
recent = messages[-3:]          # 最近 3 条消息
except_last = messages[:-1]     # 除最后一条外的所有消息

切片怎么读？方括号里写 [起点:终点]，取出从"起点"到"终点前一个"的一段（含头不含尾），两边都能省略。再加上负数下标从末尾倒数（-1 是最后一个、-2 是倒数第二……），就能读懂上面两行：

  • messages[-3:] — 从"倒数第 3 个"取到末尾 → 最后 3 条（终点省略=一直到底）
  • messages[:-1] — 从头取到"最后一个之前" → 去掉末尾那条（起点省略=从头开始）

Agent 里常用它裁剪对话历史（如"只保留最近 N 轮"来省 token）。切片对 str、tuple 同样适用。

dict — 键值对、有序（Python 3.7+）、可变

dict（字典）是"用名字查值"的容器。list 靠位置下标（tools[0]）取值，dict 则靠一个键（key）取到对应的值（value）——就像查字典：给一个词（key），翻到它的释义（value）。每一对就叫一个"键值对"，写成 "键": 值。

为什么 Agent 开发离不开它？因为 LLM 的响应、模型配置、工具参数全都是 dict：config["model"] 比"配置里的第 0 个"直观得多。

# 创建（Agent 的核心数据结构）
config = {
    "model": "gpt-4",
    "temperature": 0.7,
    "max_tokens": 1000
}

# 访问
config["model"]                 # "gpt-4"
config.get("timeout", 30)      # 带默认值的安全访问

# 修改
config["temperature"] = 0.5     # 修改
config["stream"] = True         # 新增

# 遍历
for key, value in config.items():
    print(f"{key}: {value}")

# 字典推导式
tools = {"search": 10, "calc": 5, "weather": 8}
limited = {k: min(v, 8) for k, v in tools.items()}
# {"search": 8, "calc": 5, "weather": 8}

tuple — 有序、不可变、可重复

# Agent 中用于不可变的配置
POINT = (39.9, 116.4)           # 北京坐标
API_VERSION = ("v1", "stable")

# 解包
x, y = POINT
name, version = API_VERSION

# tuple 的不可变性保护数据不被意外修改
# 适合用作 dict 的 key
locations = {
    (39.9, 116.4): "北京",
    (31.2, 121.5): "上海"
}

set — 无序、不可重复

set（集合）是一袋"不重复的东西"。它有两个特点：自动去重（同一个值放两次也只留一个）、无序（不记录先后顺序，所以不能用下标取值）。它的拿手好戏是两件事：去重（把一串有重复的值变成不重复的），以及集合运算——判断"哪些在 A 不在 B"、"A 和 B 共有哪些"。Agent 里常用它做工具去重、权限白名单检查。

# 去重（Agent 中用于去除重复工具调用）
calls = ["search", "calc", "search", "weather", "calc"]
unique_calls = set(calls)       # {"search", "calc", "weather"}

# 集合运算
allowed = {"search", "calc", "weather", "file"}
requested = {"search", "hack", "weather"}
blocked = requested - allowed   # {"hack"}
approved = requested & allowed  # {"search", "weather"}
🔑 Agent 开发关联：

Agent 系统中最常用的容器：

  • dict：配置、LLM 响应、工具参数 — 几乎无处不在
  • list：对话历史、工具列表、批量结果
  • tuple：不可变的元组数据（坐标、版本号）
  • set：去重、权限检查、已处理记录
Q 下面哪个对象可以作为 dict 的 key？
dict 的 key 必须是"可哈希（hashable）"的——通俗说就是不可变。tuple (1,2,3) 不可变，能当 key；list、dict、set 都可变，不行。
（记忆钩子：能不能当 key，看它会不会变。这也呼应第 2 节的可变/不可变。）注意：含可变元素的 tuple 如 (1, [2,3]) 也不行。
Q type({}) 的结果是什么？
{} 是空 dict，不是空 set——花括号被 dict 占用了。要建空集合只能写 set()。这是初学者最常踩的坑：type({}) → dict，type(set()) → set。

5. 推导式：Python 的数据转换利器

推导式是 Python 最强大的语法特性之一，Agent 开发中大量使用。

先看懂它怎么读。推导式就是把"建一个空列表 → for 循环 → 满足条件就 append"这三步，压成一行。它的骨架是：

[  表达式   for 变量 in 可迭代对象   if 条件  ]
   └拿什么┘  └───── 遍历谁 ──────┘  └筛选┘

三块对照普通循环，一一对应：

# 普通写法（三步）
result = []                    #  []        ← 建列表
for x in items:                #  for x in items
    if x > 0:                  #      if x > 0   ← 筛选
        result.append(x * 2)   #          x * 2  ← 拿什么

# 推导式（一行，顺序：先写"拿什么"，再写 for，最后 if）
result = [x * 2 for x in items if x > 0]

读的时候从中间的 for 起：先看"遍历谁"，再看右边"筛不筛"，最后回到左边"每个拿出来做什么"。if 可省略（不筛选时）。掌握这个骨架，下面几种推导式都是同一个模子。

列表推导式

# 传统写法
results = []
for tool in tools:
    if tool["enabled"]:
        results.append(tool["name"])

# 推导式（一行搞定）
results = [tool["name"] for tool in tools if tool["enabled"]]

# 带条件转换
statuses = ["success", "error", "success", "pending"]
icons = ["✅" if s == "success" else "❌" for s in statuses]
# ["✅", "❌", "✅", "❌"]   ← 三元只有两个分支：不是 success 的都归 ❌

字典推导式

# 从 LLM 响应中提取工具调用
response = {
    "tool_calls": [
        {"name": "search", "args": {"q": "python"}},
        {"name": "calc", "args": {"expr": "1+1"}}
    ]
}

# 提取工具名和参数
tool_map = {tc["name"]: tc["args"] for tc in response["tool_calls"]}
# {"search": {"q": "python"}, "calc": {"expr": "1+1"}}

集合推导式

# 提取所有唯一工具名
all_calls = ["search", "calc", "search", "weather"]
unique = {call for call in all_calls}
# {"search", "calc", "weather"}

嵌套推导式（谨慎使用）

# 扁平化嵌套列表
nested = [[1, 2], [3, 4], [5, 6]]
flat = [x for sublist in nested for x in sublist]
# [1, 2, 3, 4, 5, 6]

6. dict 深度操作

嵌套访问：安全取值

LLM 的响应往往是"套娃"式的多层 dict/list。取深处的值时，最直接的写法是一层层用 [] 点进去——但只要中间任何一层缺失或结构不符，就会当场报错、程序崩掉。而 LLM 的输出并不总是稳定的，所以我们需要"取不到就返回默认值、绝不崩"的安全写法。

# LLM 响应通常有多层嵌套
response = {
    "choices": [{
        "message": {
            "tool_calls": [{
                "function": {
                    "name": "search",
                    "arguments": '{"q": "python"}'
                }
            }]
        }
    }]
}

# ❌ 危险的写法（任何一层缺失就报错 KeyError / IndexError）
name = response["choices"][0]["message"]["tool_calls"][0]["function"]["name"]

第一步：朴素的安全写法——把每层的 [] 换成 .get(键, {})（第 4 节讲过 .get 带默认值不会报错）。取不到就一路返回空 dict，最后再取值：

name = (response.get("choices", [{}])[0]
                .get("message", {})
                .get("tool_calls", [{}])[0]
                .get("function", {})
                .get("name"))
# 任何一层缺失，最终得到 None，而不是崩溃

能用，但每层都手写 .get(..., {}) 太啰嗦。第二步：封装成一个通用函数 safe_get，把"要走的路径"当参数传进去。这里会用到两个新东西，先建立印象即可：

  • isinstance(d, dict)——判断 d 是不是某种类型（这里问"它还是个 dict 吗"）。本课第 7 节会细讲。
  • *keys——让函数接收任意多个路径参数，收集成一个元组。这是 L05 · 函数参数 的内容，这里知道"它能一次收一串 key"就够了。
# ✅ 通用的安全访问函数（一次处理任意深度、dict 和 list 都支持）
def safe_get(d, *keys, default=None):
    for key in keys:               # 沿着路径一层层往里走
        if isinstance(d, dict):            # 当前是 dict → 用 .get 安全取
            d = d.get(key, default)
        elif isinstance(d, list) and isinstance(key, int):  # 是 list 且 key 是下标
            d = d[key] if 0 <= key < len(d) else default
        else:                              # 走不下去了 → 返回默认值
            return default
    return d

name = safe_get(response, "choices", 0, "message", "tool_calls", 0, "function", "name")
# "search"；任何一层不对，返回 None，不崩

defaultdict：自动创建默认值

defaultdict、Counter、ChainMap 都来自 Python 自带的 collections 标准库——它是官方提供的一组"加强版容器"，不用另外安装，import 就能用。它们本质还是 dict，只是各自多了一个贴心的小能力，专治普通 dict 用起来啰嗦的场景。

from collections import defaultdict

# 统计工具调用次数
call_count = defaultdict(int)    # 默认值为 0
calls = ["search", "calc", "search", "weather", "search"]
for call in calls:
    call_count[call] += 1
# {"search": 3, "calc": 1, "weather": 1}

# 按类型分组工具
tools_by_type = defaultdict(list)  # 默认值为 []
tools = [
    {"name": "search", "type": "web"},
    {"name": "calc", "type": "math"},
    {"name": "weather", "type": "web"},
]
for tool in tools:
    tools_by_type[tool["type"]].append(tool["name"])
# {"web": ["search", "weather"], "math": ["calc"]}

ChainMap：合并多个字典

from collections import ChainMap

# Agent 配置的优先级合并
user_config = {"model": "gpt-4", "temperature": 0.9}
project_config = {"model": "gpt-3.5", "max_tokens": 500}
default_config = {"model": "gpt-3.5", "temperature": 0.7, "max_tokens": 1000}

# user > project > default
config = ChainMap(user_config, project_config, default_config)
print(config["model"])        # "gpt-4"（user 优先）
print(config["temperature"])  # 0.9（user 优先）
print(config["max_tokens"])   # 500（project 优先）

其他常用 dict 方法

# setdefault：获取值，不存在则设置默认值
cache = {}
result = cache.setdefault("key_123", compute_expensive())
# 等价于：
if "key_123" not in cache:
    cache["key_123"] = compute_expensive()
result = cache["key_123"]

# update：合并字典
base = {"model": "gpt-4", "temperature": 0.7}
override = {"temperature": 0.9, "stream": True}
base.update(override)  # {"model": "gpt-4", "temperature": 0.9, "stream": True}

# dict | 运算符（Python 3.9+）
merged = base | override  # 创建新字典，不修改原字典

# Counter：计数器（Agent 中统计 token、工具调用）
from collections import Counter
words = ["hello", "world", "hello", "python", "hello"]
word_count = Counter(words)
print(word_count.most_common(2))  # [("hello", 3), ("world", 1)]

LLM 响应是嵌套 dict，Agent 配置有多层优先级，工具参数需要安全访问 — 这些都是 Agent 开发的日常。掌握 dict 深度操作是基本功。

7. 类型转换与类型检查

# 常用类型转换
int("42")           # 42
float("3.14")       # 3.14
str(100)            # "100"
list("hello")       # ["h", "e", "l", "l", "o"]
dict([("a", 1), ("b", 2)])  # {"a": 1, "b": 2}

# 类型检查
isinstance(42, int)           # True
isinstance("hi", str)         # True
isinstance([1, 2], list)      # True
isinstance({"a": 1}, dict)    # True

# 检查多个类型
isinstance(42, (int, float))  # True
💡 面试常见问题：

"isinstance 和 type 的区别？"

答：isinstance 支持继承关系检查（子类也返回 True），type 精确匹配类型。一般推荐用 isinstance。

任务 5：safe_get 实现

def safe_get(d, *keys, default=None):
    current = d
    for key in keys:
        if isinstance(d, dict):
            d = d.get(key, default)
        elif isinstance(d, list) and isinstance(key, int):
            d = d[key] if 0 <= key < len(d) else default
        else:
            return default
    return d

面试常见问题

Q1：Python 可变类型和不可变类型的区别？

答：不可变类型（int/str/tuple）的值不能修改，修改会创建新对象。可变类型（list/dict/set）可以原地修改。不可变类型可以作为 dict 的 key，可变类型不行。

Q2：Python dict 的底层实现是什么？

答：哈希表（Hash Table）。通过 key 的 hash 值定位存储位置，查找时间复杂度 O(1)。Python 3.7+ dict 保持插入顺序，是因为底层额外维护了一个链表。

Q3：tuple 和 list 的区别？什么时候用 tuple？

答：tuple 不可变，list 可变。tuple 可以作为 dict 的 key，list 不行。tuple 比 list 更省内存。用 tuple 的场景：数据不应被修改时（坐标、RGB 颜色）、需要作为 dict key 时。

Q4：defaultdict 和普通 dict 有什么区别？

答：defaultdict 在访问不存在的 key 时，会自动创建默认值（由构造参数指定），而不是抛出 KeyError。常用于计数和分组场景。

Q5：什么是可变默认参数陷阱？怎么避免？

答：函数的默认参数如果是可变对象（如 list/dict），会在函数定义时创建一次，之后每次调用共享同一个对象。避免方法：用 None 作为默认值，在函数体内创建新对象。

Q6：isinstance 和 type 的区别？

答：isinstance 支持继承关系检查（子类也返回 True），type 精确匹配类型。一般推荐用 isinstance，更符合多态设计。
