1
检查 & 安装 Python

打开终端（Mac: Terminal / Windows: PowerShell），运行：

python3 --version

应该看到类似 Python 3.11.x 或 3.12.x 的输出。

结果操作
3.11 或更高✅ 跳到下一步
3.10 或更低⬇️ 需要升级
command not found⬇️ 需要安装

安装/升级 Python：

# Mac（推荐用 Homebrew）
brew install python@3.12

# 或者用 pyenv 管理多版本（推荐）
curl https://pyenv.run | bash
pyenv install 3.12
pyenv global 3.12

# Windows
# 从 https://www.python.org/downloads/ 下载安装
# 安装时勾选 "Add Python to PATH"

安装后重新检查版本：

python3 --version
# 应该输出 Python 3.11.x 或 3.12.x
2
安装 uv 包管理工具

uv 是 2024-2025 年 Python 生态最重要的工具之一，比 pip 快 10-100 倍。Agent 开发中你会频繁安装依赖，uv 能节省大量时间。

# Mac / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

验证安装：

uv --version
# 应该输出类似 uv 0.x.x

uv 常用命令速查：

命令作用
uv init myproject创建新项目
uv add requests安装依赖
uv add --dev pytest安装开发依赖
uv run python main.py在虚拟环境中运行脚本
uv sync同步所有依赖
uv pip list查看已安装的包

配置 VS Code

VS Code 是 Agent 开发最主流的编辑器。安装以下扩展：

# 用命令行安装扩展（如果已安装 VS Code CLI）
code --install-extension ms-python.python
code --install-extension ms-python.vscode-pylance
code --install-extension charliermarsh.ruff
code --install-extension ms-python.debugpy

或者在 VS Code 中手动安装：

  1. 打开 VS Code
  2. 按 Cmd+Shift+X（Mac）或 Ctrl+Shift+X（Windows）打开扩展面板
  3. 搜索并安装：
    • Python (ms-python.python) — Python 语言支持
    • Pylance (ms-python.vscode-pylance) — 智能提示和类型检查
    • Ruff (charliermarsh.ruff) — 代码格式化和 lint
    • Python Debugger (ms-python.debugpy) — 调试支持

4
创建第一个项目 & 虚拟环境

虚拟环境让每个项目的依赖互相隔离，避免版本冲突。这是 Python 开发的基本纪律。

# 创建项目目录
mkdir my-first-agent
cd my-first-agent

# 用 uv 初始化项目（自动创建虚拟环境）
uv init

# 你会看到这样的目录结构：
# my-first-agent/
# ├── .python-version    # Python 版本
# ├── pyproject.toml     # 项目配置
# ├── README.md
# └── hello.py           # 示例文件

查看 pyproject.toml：

[project]
name = "my-first-agent"
version = "0.1.0"
requires-python = ">=3.11"

运行第一个脚本：

uv run hello.py
# 应该输出: Hello from my-first-agent!
5
安装常用依赖

Agent 开发最常用的几个包，先装上：

# 核心依赖
uv add httpx           # 异步 HTTP 客户端（调 LLM API 用）
uv add pydantic        # 数据验证（Agent 工具定义用）
uv add python-dotenv   # 环境变量管理（API key 存储用）

# 开发依赖
uv add --dev pytest    # 测试框架
uv add --dev ruff      # 代码 lint 和格式化
uv add --dev mypy      # 类型检查

验证安装：

uv pip list
# 应该能看到 httpx, pydantic, pytest 等
6
配置环境变量（API Key）

LLM API 需要 API Key。我们用 .env 文件管理，永远不要把 key 写在代码里。

# 创建 .env 文件
touch .env

在 .env 中添加（后续课程会用到）：

# .env（不要提交到 Git！）
OPENAI_API_KEY=sk-xxx
ANTHROPIC_API_KEY=sk-ant-xxx

在 .gitignore 中添加：

# .gitignore
.env
__pycache__/
*.pyc
.venv/

在 Python 中使用：

from dotenv import load_dotenv
import os

load_dotenv()  # 加载 .env 文件

api_key = os.getenv("OPENAI_API_KEY")
print(f"Key loaded: {api_key[:10]}...")  # 只打印前10位

自测练习

Q1: 虚拟环境的作用是什么？

让 Python 运行更快 隔离项目依赖，避免版本冲突 自动生成 requirements.txt 提供在线编程环境

Q2: 为什么 API Key 不能写在代码里？

代码会变长 Python 不支持 提交到 Git 后别人能看到，造成安全风险 会影响代码运行速度

Q3: uv add --dev pytest 中的 --dev 表示什么？

安装开发版（不稳定版） 仅在开发时使用，不会打包到生产环境 需要开发者权限才能安装 安装到系统 Python 而非虚拟环境

实战任务

任务：搭建完整的 Agent 开发项目

按照以下步骤，从零搭建一个可运行的项目：

  1. 用 uv init agent-hello 创建项目
  2. 安装依赖：uv add httpx pydantic python-dotenv
  3. 创建 .env 文件（先随便写个假的 key）
  4. 创建 main.py，写入以下代码：
"""我的第一个 Agent 项目骨架"""
from dotenv import load_dotenv
from pydantic import BaseModel
import os

# 加载环境变量
load_dotenv()

class Message(BaseModel):
    """消息模型 - 后续 Agent 的基础数据结构"""
    role: str
    content: str

def main():
    # 验证环境
    api_key = os.getenv("OPENAI_API_KEY", "not-set")
    print(f"✅ 项目初始化成功！")
    print(f"✅ API Key: {api_key[:10]}..." if len(api_key) > 10 else f"⚠️ API Key: {api_key}")

    # 验证 Pydantic
    msg = Message(role="user", content="Hello, Agent!")
    print(f"✅ Pydantic 工作正常: {msg.model_dump()}")

    # 验证类型提示
    def greet(name: str) -> str:
        return f"你好, {name}! 准备好学 Agent 了吗？"

    print(f"✅ {greet('同学')}")

if __name__ == "__main__":
    main()
  1. 运行：uv run main.py
  2. 看到 3 个 ✅ 就算成功！
