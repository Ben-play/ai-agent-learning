· 幻觉问题全解 — 预训练统计错误、评估鼓励猜测与其他工程成因；Self-Consistency/RAG/引用核验的能力边界

· 推理能力与 Adaptive Thinking — 区分模型能力、adaptive thinking、effort，并按质量/延迟/Token 实测路由
· 看懂 Benchmark — 不只看模型分数，还核对数据污染、Agent scaffold、工具与预算；用开发集调参、隔离测试集验收
· 模型选型实战 — 区分开放权重、托管服务与自托管；合规看地域/合同/保留策略，总成本用真实负载测算，不按“开源/闭源”标签拍板

Module 2.3 · Token 经济学：理解多轮累计成本；按静态前缀占比和命中率评估 Prompt Caching，按业务质量评测 Model Routing；案例降幅不作保证，Batch/压缩/输出控制均按厂商和场景验证

LLM API 工程实践

14 课 3 周
▼
API 面试
Module 3.1 · API 基础：主流 API 快速上手（OpenAI/Anthropic/Google）、Streaming 流式输出

Module 3.2 · 核心能力（Agent 必备）：
· Function Calling — 工具定义、模型调用工具流程、多工具选择
· Structured Output — Structured Outputs（约束解码/strict mode，token 级保证符合 Schema）≠ 旧 JSON mode、Pydantic 约束、无法保证时的验证与重试兜底
· 多模态 API — 图片理解（Vision）、音频转录（Whisper）

Module 3.3 · 工程实践（生产级）：
· Context Window 管理 — 上下文压缩、滑动窗口、摘要记忆
· 错误处理与重试策略 — 速率限制（429）、指数退避 + 抖动（full jitter，防重试风暴）、重试预算、幂等键（idempotency key，让有副作用的工具调用可安全重试）
· 模型路由与 Fallback — 主备模型策略、AI Gateway 模式（LiteLLM）
· LLM 可观测性基础 — 调用日志、Token 用量追踪、成本告警；OpenTelemetry GenAI 语义约定（gen_ai.* span，厂商无关标准）+ Langfuse

Module 3.4 · 工具工程与 Function Calling（v7 新增 · P0 实战必修）：
· Tool Schema 设计 — 用 Pydantic / JSON Schema 定义工具、strict mode、参数描述如何影响模型选择
· 完整 Function Calling 循环 — 模型请求工具 → 执行 → 回填结果 → 再推理，多轮 / 并行调用
· 健壮性 — 参数校验失败如何反馈给模型重试、流式响应中增量解析工具调用、工具定义占多少 Token
· 工具注册系统 — 用装饰器做可扩展的 Tool Registry（衔接 Phase 1）

Module 3.5 · 成本工程（v7 强化）：2026 降本优先级 — ① 原生 Prompt Caching（OpenAI/Anthropic/Google，零改动、输入成本最高降 ~90%，关键是「静态前缀 + 动态后缀」缓存键设计）＞ ② 语义缓存（semantic cache：按语义相似度命中，GPTCache/Redis，与前缀缓存互补）＞ ③ 模型路由（LiteLLM）＞ ④ 提示压缩（LLMLingua）＞ ⑤ 小模型蒸馏 ＞ ⑥ Batch API

"Streaming 好处" / "Function Calling 原理" / "如何设计好的 Tool Schema" / "并行工具调用怎么处理" / "Structured Outputs 与 JSON mode 区别" / "Context Window 超限" / "如何处理速率限制（退避+抖动）" / "有副作用的工具调用如何安全重试（幂等）" / "主模型挂了怎么办" / "Prompt Caching 与语义缓存的区别" / "一个 Agent 每月 $10k 如何砍到 $5k" — 共 14+ 道高频题

Agent 核心架构：Loop、Harness 与工具设计

10-12 课 3-4 周
▼
Agent Harness
Agent Loop（核心执行循环）：Observe → Think → Act → Observe 循环、循环控制、错误恢复与重试策略

Agent Harness（2026 主导架构）：Anthropic 发布 3 篇工程论文定义的新范式。"好模型 + 好 harness > 好模型 + 差 harness"：
· 棘轮效应（Ratchet）：每次 Agent 犯错，就加一条规则防止再犯
· 行为驱动设计：从"期望行为"反推 harness 组件
· 生命周期管理、工具执行调度、完成标准、错误恢复

Context Engineering 进阶（Anthropic 官方长任务技法）：compaction（接近上限时压缩对话、带摘要重启）、structured note-taking / agentic memory（上下文外持久化笔记，用时再拉回）、sub-agent 架构（子代理用干净窗口探索、只回 1–2k token 精炼摘要）、just-in-time 检索 / progressive disclosure（存轻量标识符、运行时按需加载 vs 预取）、滑动窗口、Token 预算分配

工具设计哲学（2026 关键技能）：Schema 设计、错误处理、粒度控制、工具组合、工具测试

经典模式：ReAct、Plan-and-Execute、Reflexion

记忆与 Human-in-the-Loop：短期/长期/工作记忆设计、Mem0、人工审批节点

实战项目：从零实现一个完整的 Agent Harness — ReAct 模式 + 自定义工具 + Context Engineering + 记忆系统 + 人工审批
