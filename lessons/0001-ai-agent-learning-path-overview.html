Agent 核心架构：Loop、Harness 与工具设计

10-12 课 3-4 周
▼
Agent Harness
Agent Loop（核心执行循环）：Observe → Think → Act → Observe 循环、循环控制、错误恢复与重试策略

Agent Harness（2026 主导架构）：Anthropic 发布 3 篇工程论文定义的新范式。"好模型 + 好 harness > 好模型 + 差 harness"：
· 棘轮效应（Ratchet）：每次 Agent 犯错，就加一条规则防止再犯
· 行为驱动设计：从"期望行为"反推 harness 组件
· 生命周期管理、工具执行调度、完成标准、错误恢复

Context Engineering 进阶：动态上下文组装、压缩/摘要策略、滑动窗口、记忆注入、Token 预算分配

工具设计哲学（2026 关键技能）：Schema 设计、错误处理、粒度控制、工具组合、工具测试

经典模式：ReAct、Plan-and-Execute、Reflexion

记忆与 Human-in-the-Loop：短期/长期/工作记忆设计、Mem0、人工审批节点

实战项目：从零实现一个完整的 Agent Harness — ReAct 模式 + 自定义工具 + Context Engineering + 记忆系统 + 人工审批
