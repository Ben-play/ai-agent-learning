阶段 1 · Python 基础与 Agent 导向工程素养

从基础语法到 Agent 开发必备的工程技能，系统性夯实 Python 功底。

📚 共 3 大部分 · 10 个模块 · 16 课 ⏱ 预计 2-3 周完成
为什么从基础开始？
Agent 开发看似只需要"调 API"，但实际上：
· Dict/JSON 操作不熟练 → 处理 LLM 返回的复杂 JSON 会很痛苦
· 装饰器理解不深 → Agent 框架源码看不懂，@tool/@chain 用不好
· 类型提示不会写 → Pydantic Schema 定义不出来，Structured Output 用不了
· 异步不会写 → LLM 并发调用直接卡死
基础不牢，地动山摇。

解析 JSON Lines 流 — 模拟本地日志/自定义事件的 JSON Lines 流，逐行解析、拼接完整内容、区分坏行与半行截断
L1030min
异常处理、日志与上下文管理器
try/except/else/finally、自定义异常（AgentError、ToolError）、异常链（raise from）、with 语句与 __enter__/__exit__、contextlib（@contextmanager，仅负责进入/退出与清理，超时/重试是另外的职责）；logging 结构化日志（logger/level/handler/格式化，logger.exception 只用于真实 except 块，生产 Agent 从第一天就该用，而非 print 调试）；tenacity —— 只对临时性异常重试的标准库（stop_after_attempt 总尝试次数、reraise=True 抛原始异常，别重复造轮子）
实现一个 API 调用上下文管理器 — 记录进入/退出与耗时、用 logging 记录每次调用与失败原因、退出时清理资源并重抛异常，选做叠加 tenacity 对临时异常做重试，模拟 LLM API 调用场景

类型提示与数据验证

3.3

网络请求与 HTTP Agent 核心

L1530min

异步编程与并发

学习建议

Part A 快速过——你有基础，2 天内完成，重点查漏补缺。每课 20-30 分钟。
Part B 是重点——装饰器、@dataclass、JSON 操作是 Agent 框架的底层，必须真正理解。每课 40-60 分钟。
Part C 是核心——生成器/Streaming、类型提示、Pydantic、httpx 网络请求、异步并发，每个都直接对应 Agent 开发场景。其中 httpx + 异步是「发起并发 LLM 调用」的地基，务必动手写。每课 60+ 分钟,多写代码。

练习方式：每课结束后完成实战练习。练习都是 Agent 开发中的真实场景，写完的代码后面课程会直接复用。
