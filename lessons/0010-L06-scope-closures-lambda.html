作用域、闭包与 Lambda

闭包是"带记忆的函数" — Agent 里的计数器、限流器、装饰器都靠它

💡 为什么这课重要？

装饰器（L11）、限流器、状态计数器——这些 Agent 里天天用的东西，底层都是闭包：一个函数"记住"了它出生时的环境变量。理解闭包，你才看得懂 @tool 是怎么工作的。

而 lambda + 高阶函数（map/filter/sorted 的 key），是处理 LLM 返回的列表数据的利器——排序工具、过滤结果、聚合成本，一行搞定。

学习目标

完成本课后，你将能够：

  • 用 LEGB 规则判断一个变量到底指向谁
  • 解释闭包的原理，并用它保存状态（面试常问）
  • 正确使用 global / nonlocal
  • 用 lambda + sorted(key=) 排序结构化数据
  • 用 map / filter / reduce / partial 做数据变换

1. LEGB：变量到底指向谁

Python 查找一个名字时，按 L → E → G → B 的顺序找：

  • Local 局部（当前函数内）
  • Enclosing 外层函数（闭包所在层）
  • Global 模块全局
  • Built-in 内置（len、print…）
x = "global"

def outer():
    x = "enclosing"
    def inner():
        # 这里读 x：Local 没有 → 找 Enclosing → "enclosing"
        return x
    return inner()

print(outer())   # enclosing
Q LEGB 中，函数优先在哪一层找变量？
查找顺序是 L→E→G→B：先看自己函数内部（Local），找不到才逐层往外。理解这个顺序，才能预测变量到底取到哪个值，也才能理解闭包为什么能"看见"外层变量。

2. 闭包：带记忆的函数

当内层函数引用了外层函数的变量，并被返回出去，它就"记住"了那些变量——这就是闭包。修改外层变量要用 nonlocal：

def make_counter():
    calls = 0
    total_ms = 0
    def record(ms):
        nonlocal calls, total_ms      # 声明：改的是外层的变量，不是新建局部
        calls += 1
        total_ms += ms
        return {"calls": calls, "total_ms": total_ms}
    return record

counter = make_counter()
counter(10)
print(counter(20))   # {'calls': 2, 'total_ms': 30}  ← 状态被记住了

没有 nonlocal，calls += 1 会被当成"新建一个局部 calls"，报 UnboundLocalError。

🔑 Agent 开发关联：

闭包是"不用类也能保存状态"的轻量方案。Agent 里的工具调用计数器、令牌桶限流器、重试计数都能用闭包实现。更重要的是——装饰器（L11）本质就是返回闭包，理解这里，L11 会非常顺。

💡 面试常见问题：

"什么是闭包？global 和 nonlocal 区别？"

答：闭包是记住了外层作用域变量的函数。global 声明修改的是模块全局变量；nonlocal 声明修改的是外层函数（enclosing）的变量。不写声明时，函数内赋值会新建局部变量。

3. Lambda + 高阶函数：处理列表数据

lambda 是"一次性的小函数"，最常配 sorted / map / filter 用来处理 LLM 返回的列表：

tools = [
    {"name": "search", "cost": 10},
    {"name": "calc", "cost": 3},
    {"name": "weather", "cost": 8},
]

# 按成本排序（key 决定"按什么排"）
cheapest = sorted(tools, key=lambda t: t["cost"])[0]
print(cheapest["name"])          # calc

# map：提取所有工具名
names = list(map(lambda t: t["name"], tools))     # ['search','calc','weather']

# filter：留下便宜的工具
cheap = list(filter(lambda t: t["cost"] < 9, tools))   # calc, weather

# reduce：聚合总成本
from functools import reduce
total = reduce(lambda acc, t: acc + t["cost"], tools, 0)   # 21

# partial：固定住某个参数，生成新函数
from functools import partial
def call(model, prompt): return f"{model}: {prompt}"
call_claude = partial(call, "claude")
print(call_claude("你好"))       # claude: 你好

提示：能用推导式（L03）就用推导式，可读性更好；map/filter 在配合现成函数、或链式场景时更简洁。

Q sorted(data, key=lambda x: x["cost"]) 里 key 的作用是？
key 是一个"取排序依据"的函数，对每个元素调用它、按返回值排序。这里按 x["cost"] 排。key 不改变元素本身，只决定排序顺序——处理 LLM 返回的字典列表时极其常用。

知识图谱

作用域 LEGB
├── Local → 当前函数
├── Enclosing → 外层函数（闭包层）
├── Global → 模块全局（global 声明可改）
└── Builtin → 内置

闭包 = 记住外层变量的函数
├── nonlocal → 改 enclosing 变量
├── 用途：计数器 / 限流 / 重试状态
└── 装饰器的底层（→ L11）

lambda + 高阶函数
├── sorted(key=lambda ...) → 排序依据
├── map / filter → 变换 / 筛选
├── reduce → 聚合
└── partial → 固定参数生成新函数

实战练习

练习：用闭包实现一个 Agent 计数器

实现一个记录工具调用的计数器：每次调用记录"调用次数"和"累计耗时"。先自己写，再看答案。

任务清单

  1. 写 make_tracker()，返回一个内部函数 record(tool_name, ms)
  2. 用闭包保存：总调用次数、累计耗时、每个工具各自的调用次数
  3. record 返回当前统计快照（dict）
  4. 关键：用 nonlocal 修改外层计数
💡 点击查看参考答案 
from collections import defaultdict

def make_tracker():
    calls = 0
    total_ms = 0
    per_tool = defaultdict(int)      # 每个工具的次数

    def record(tool_name, ms):
        nonlocal calls, total_ms
        calls += 1
        total_ms += ms
        per_tool[tool_name] += 1     # dict 是可变对象，不用 nonlocal 也能改内容
        return {
            "calls": calls,
            "total_ms": total_ms,
            "per_tool": dict(per_tool),
        }
    return record


track = make_tracker()
track("search", 120)
print(track("search", 80))
print(track("calc", 15))
# {'calls': 2, 'total_ms': 200, 'per_tool': {'search': 2}}
# {'calls': 3, 'total_ms': 215, 'per_tool': {'search': 2, 'calc': 1}}

思考题

  • 为什么 per_tool（dict）不需要 nonlocal，而 calls（int）需要？（提示：可变 vs 不可变，回顾 L03）
  • 如果两个地方各 make_tracker() 一次，它们的计数会互相影响吗？

面试常见问题

Q1：什么是闭包？举个实际用途。

答：闭包是"记住了定义时外层作用域变量"的函数。用途：不建类就保存状态（计数器、限流器）、以及装饰器的实现基础。

Q2：global 和 nonlocal 有什么区别？

答：global 让函数内的赋值作用到模块全局变量；nonlocal 作用到外层函数的变量。都用于"我要改的是外面那个，别新建局部"。

Q3：为什么闭包里 count += 1 不加 nonlocal 会报错？

答：因为对变量赋值会让 Python 把它当成局部变量，而 += 需要先读取它——读一个"还没赋值的局部变量"就抛 UnboundLocalError。加 nonlocal 表明改的是外层变量。

Q4：map/filter 和列表推导式怎么选？

答：多数情况推导式可读性更好、更 Pythonic。map/filter 在直接复用现成函数（如 map(str, xs)）或需要惰性求值时更简洁。

总结

  • 变量查找按 LEGB：Local → Enclosing → Global → Builtin
  • 闭包 = 记住外层变量的函数，是"轻量状态保存"和装饰器的基础
  • 改外层变量：global（全局）/ nonlocal（外层函数）
  • 可变对象（dict/list）改内容不需要 nonlocal，重新赋值才需要
  • lambda + sorted(key=) / map / filter / reduce / partial 处理列表数据
