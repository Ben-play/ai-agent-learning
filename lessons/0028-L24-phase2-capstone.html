💡 为什么这课重要？

前面 7 课你分别学了 LLM 的本质与参数（L17）、Token 计数（L18）、幻觉（L19）、推理模型、能力边界、Benchmark 与选型框架（L22）、Token 经济学（L23）。它们现在还是散的知识点。

选型要回答的是：这个场景谁达标，有什么证据，花多少？本课用同一份虚构申请、两种模拟 provider 响应和重复运行记录，生成一份可核对的模型体检报告。整段可离线复制运行，不需要 Key 或第三方库，也不是对真实模型的排名。

学习目标

完成本课后，你将能够：

  • 把"选哪个模型"拆成能力 / 幻觉 / 成本三个可测量的维度
  • 区分 OpenAI tokenizer 估算与 Claude 官方 count_tokens / response usage（复用 L18）
  • 用两个 Provider Adapter 将不同载荷映射为同一种观察记录，保留原始响应
  • 区分一致性筛查与精确事实、独立证据核对（复用 L19）
  • 从同一份逐次记录汇总质量、事实、证据和成本，先过硬门再排名（复用 L22/L23）

1. 固定任务与比较条件

所有候选处理同一份虚构资助申请：根据预算基数和政策上限，返回带符号的精确调整额及对应证据 ID，每个候选运行两次。用独立真值核对金额，用固定证据语料核对引用，用预先给定的评分记录表示质量。每次使用量、重试和人工升级一起进入成本。

实际选型还应固定 prompt、系统指令、工具、输出上限、rubric、次数与预算；不能强求不同 API 接受同一采样字段。这一题的两次模拟观测只验证评测流程，不足以评价真实模型的能力。

2. Token 估算与成本口径（复用 L18 / L23）

真实调用前用目标厂商的方法估算；调用后用 response usage 和单价对账。输入和输出分别计价，缓存的读写费率要按模型、平台和 TTL 核对；完整成本还包括重试与人工升级。下方报告直接使用固定的模拟 usage 和教学单价，不请求模型，也不会把字符数当 Token。

选做：OpenAI 编码文本计数（不用于离线验收）

安装依赖是终端命令。tiktoken.get_encoding() 在首次加载、词表缓存未命中时可能联网下载；缓存预备好才可离线计数。这只计算匹配 OpenAI 编码的文本，不包含聊天结构开销，不能用作 Claude 的精确账单。

python -m pip install tiktoken
import tiktoken

encoding = tiktoken.get_encoding("o200k_base")
print(len(encoding.encode("用一句话解释什么是向量数据库。")))

Claude 的 messages.count_tokens 是有凭据的远程请求，用完整结构估算输入；估算与实际 usage 可能不同。完整计数示例见 L18，本课不需要运行。

Q 跨厂商估算 Token 时，哪种做法最可靠？
OpenAI 匹配编码可用 tiktoken；Claude 用 messages.count_tokens 估算完整请求，调用后再看 response.usage。跨厂商共用一个 tokenizer 只能粗估，不能冒充精确账单。

3. Provider Adapter 只统一业务记录

两个模拟 adapter 从不同的响应字段得到同一种 Observation。原始载荷不改；解析、事实评分和门槛都由评测层处理。真实 API 的认证、请求参数、响应内容块和 usage 解析留在各自 adapter 内，不把 OpenAI 的 choices 当成通用协议。

选读：Claude SDK 远程请求（不属于离线验收）

以下片段演示 SDK 调用的边界；若实际调用需要另装 SDK、有有效凭据并联网，可能产生费用。离线报告与课末自检都不调用它。真实接入前核对所用 API 版本与模型能力，例如 Claude Messages API 2026-10-21 版不接受 temperature、top_p、top_k。

python -m pip install anthropic
from anthropic import AsyncAnthropic


async def call_claude(client: AsyncAnthropic, prompt: str):
    return await client.messages.create(
        model="claude-opus-5-5",
        max_tokens=1_024,
        thinking={"type": "adaptive"},
        output_config={"effort": "medium"},
        messages=[{"role": "user", "content": prompt}],
    )

这段只定义远程调用函数；接入时把返回的内容块、usage 和原始响应留在 Claude adapter 边界内处理。真实批量调用可按 L16 加并发限制；固定离线记录不需要异步。

Q 跨厂商模型评测中，Provider Adapter 应统一什么？
Adapter 按各自 API 版本与模型处理认证、请求字段、响应内容块和 usage，在评测流程里统一的是业务结果，不是厂商原始 JSON。

4. 一致性筛查不等于事实核对（复用 L19）

  • 一致性：成功回答只去除首尾空白，保留 +、- 和小数点。两次都答 +3.14 只能说明稳定；不足两份有效文本就不判断。
  • 精确事实：本题只收一个十进制数字，可带前导符号，不接受单位或额外标点。用 Decimal 与独立真值比较：-3.14、+3.14 和 -314 不是同一个数。原始答案和载荷另外保留，供复核。
  • 证据：将引用去重，再核对是否覆盖本题所需的来源。数值正确、但缺少证据也不能过关。本例由题库预先标注证据与题目的关系；真实评测还要核对来源内容是否支持相应主张。

5. 从逐次观察到体检报告

最佳实践：逐次过硬门，再在合格集合内排名

每次运行都必须成功，事实正确、证据齐全且质量至少 80/100。均值好看、回答稳定或成本便宜，都不能补偿某次不达标。只有合格候选参与归一化：质量越高越好（权重 70%），同一批任务的完整成本越低越好（30%）；同值的指标不区分候选。不合格者仍留在报告中；全不合格就不选，排名也不等于生产路由。

复制下面整个 Python 块到 model_report.py，用 Python 3.11+ 在终端运行：python model_report.py --report。不需要复制前面的可选片段，也不需要安装、Key 或联网。

输入是虚构的资助申请、预先给出的独立质量评分与固定 usage。费率用教学值（美元 / 百万 Token），重试与人工升级用百万分之一美元，三项相加得到逐次美元成本。报告的事实错误分母是成功运行数；证据覆盖均值包含失败（按 0 计），质量均值只计有评分的成功运行。

import re
import sys
from copy import deepcopy
from dataclasses import dataclass
from decimal import Decimal

CASE = "grant-adjustment-07"
FIXTURE = "grant-v1: proposed $100.00; cap $96.86"
TRUTH = Decimal("-3.14")
EVIDENCE_CORPUS = {
    "rule-base": "Proposed eligible budget: $100.00.",
    "rule-cap": "Policy cap: $96.86.",
    "unrelated-note": "Use the latest application form.",
}
REQUIRED_EVIDENCE = {"rule-base", "rule-cap"}
PRICES = {"alpha": (3, 15), "beta": (2, 10)}  # synthetic USD per million tokens


@dataclass(frozen=True)
class Observation:
    candidate: str
    provider: str
    case_id: str
    fixture: str
    repeat_id: str
    ok: bool
    raw_response: dict
    raw_answer: str | None
    evidence_ids: tuple[str, ...]
    quality: int | None
    cost_usd: Decimal
    failure: str | None


def adapt_alpha(raw):
    usage = raw["usage"]
    return (
        raw["status"] == "ok", raw.get("output"), tuple(raw.get("citations", ())),
        (usage["input_tokens"], usage["output_tokens"]), raw.get("error"),
    )


def adapt_beta(raw):
    return (
        raw["ok"], raw.get("answer"), tuple(raw.get("evidence_ids", ())),
        raw["tokens"], raw.get("failure"),
    )


ADAPTERS = {"alpha": adapt_alpha, "beta": adapt_beta}


def observe(candidate, provider, case, fixture, repeat, raw, quality, retry=0, escalation=0):
    ok, answer, evidence_ids, (input_tokens, output_tokens), failure = ADAPTERS[provider](raw)
    in_price, out_price = PRICES[provider]
    base = input_tokens * in_price + output_tokens * out_price
    cost = Decimal(base + retry + escalation) / 1_000_000
    return Observation(
        candidate, provider, case, fixture, repeat, ok, deepcopy(raw), answer,
        evidence_ids, quality, cost, failure,
    )


def parse_amount(answer):
    if answer is None:
        return None
    text = answer.strip()
    if re.fullmatch(r"[+-]?[0-9]+(?:\.[0-9]+)?", text):
        return Decimal(text)
    return None


def score(item):
    seen = set(item.evidence_ids) & EVIDENCE_CORPUS.keys()
    factual = item.ok and parse_amount(item.raw_answer) == TRUTH
    coverage = len(seen & REQUIRED_EVIDENCE) / len(REQUIRED_EVIDENCE) if item.ok else 0.0
    return item, factual, coverage


def consistency(items):
    answers = [
        item.raw_answer.strip() for item in items
        if item.ok and item.raw_answer and item.raw_answer.strip()
    ]
    if len(answers) < 2:
        return "n/a"
    return "stable" if len(set(answers)) == 1 else "varies"


def summarize(name, items):
    trials = [score(item) for item in items]
    quality = [item.quality for item in items if item.ok and item.quality is not None]
    return {
        "name": name, "trials": trials, "consistency": consistency(items),
        "checked": sum(item.ok for item in items),
        "fact_errors": sum(item.ok and not factual for item, factual, _ in trials),
        "evidence": sum(coverage for _, _, coverage in trials) / len(trials) if trials else 0.0,
        "quality": sum(quality) / len(quality) if quality else None,
        "cost_usd": sum((item.cost_usd for item in items), Decimal(0)),
        "failures": [item.failure for item in items if not item.ok],
    }


def passes(row):
    return bool(row["trials"]) and all(
        item.ok and factual and coverage == 1.0
        and item.quality is not None and item.quality >= 80
        for item, factual, coverage in row["trials"]
    )


class NoQualifiedCandidate(RuntimeError):
    pass


def normalize(value, values, *, lower_is_better=False):
    low, high = min(values), max(values)
    if low == high:
        return 0.0
    score = float((value - low) / (high - low))
    return 1.0 - score if lower_is_better else score


def decide(rows):
    qualified = [row for row in rows if passes(row)]
    if not qualified:
        raise NoQualifiedCandidate("no grant-review candidate passes gates")
    qualities = [row["quality"] for row in qualified]
    costs = [row["cost_usd"] for row in qualified]
    return max(qualified, key=lambda row: (
        0.7 * normalize(row["quality"], qualities)
        + 0.3 * normalize(row["cost_usd"], costs, lower_is_better=True)
    ))


def alpha(text, citations, output_tokens=20):
    return {
        "status": "ok", "output": text, "citations": citations,
        "usage": {"input_tokens": 100, "output_tokens": output_tokens},
        "claimed_factual": 1.0, "claimed_evidence": 1.0,
    }


def beta(text, evidence_ids, output_tokens=20, failure=None):
    return {
        "ok": failure is None, "answer": text, "evidence_ids": evidence_ids,
        "tokens": (100, output_tokens), "failure": failure,
        "claimed_evidence": 1.0,
    }


BOTH = ("rule-base", "rule-cap")
# Each run: (repeat ID, raw response, independent quality, retry, escalation).
SAMPLES = {
    "safe-a": ("alpha", [
        ("a-1", alpha(" -3.14 ", (*BOTH, "rule-cap")), 88, 100, 200),
        ("a-2", alpha("-3.14", BOTH), 90, 0, 100),
    ]),
    "safe-b": ("beta", [
        ("b-1", beta("-3.14", BOTH), 83, 0, 0),
        ("b-2", beta("-3.14", BOTH), 82, 100, 0),
    ]),
    "stable-wrong": ("alpha", [
        ("w-1", alpha("+3.14", BOTH, 4), 98, 0, 0),
        ("w-2", alpha("+3.14", BOTH, 4), 99, 0, 0),
    ]),
    "failed-candidate": ("beta", [
        ("f-1", beta("-3.14", BOTH), 99, 0, 0),
        ("f-2", beta(None, (), 0, "provider timeout"), None, 100, 300),
    ]),
    "compensating": ("beta", [
        ("c-1", beta("-3.14", ("rule-base", "unrelated-note", "forged-id"), 10), 90, 0, 0),
        ("c-2", beta("-314", BOTH, 10), 90, 0, 0),
    ]),
}


def build_report():
    return [
        summarize(name, [observe(name, provider, CASE, FIXTURE, *sample) for sample in samples])
        for name, (provider, samples) in SAMPLES.items()
    ]


def render_report(rows):
    lines = ["model | runs | consistency | fact errors | evidence | quality /100 | total USD | gate | failed"]
    for row in rows:
        errors = f"{row['fact_errors']}/{row['checked']}" if row["checked"] else "n/a"
        quality = "n/a" if row["quality"] is None else f"{row['quality']:.1f}"
        gate = "PASS" if passes(row) else "FAIL"
        lines.append(
            f"{row['name']} | {len(row['trials'])} | {row['consistency']} | {errors} | "
            f"{row['evidence']:.0%} | {quality} | {row['cost_usd']:.6f} | {gate} | {len(row['failures'])}"
        )
    try:
        winner = decide(rows)["name"]
    except NoQualifiedCandidate:
        winner = "none qualified"
    lines.append(f"selected: {winner}")
    return "\n".join(lines)


if __name__ == "__main__" and sys.argv[1:] == ["--report"]:
    print(render_report(build_report()))

读报告：stable-wrong 两次答案一致、证据齐全且便宜，仍以 2/2 的事实错误被拒；compensating 两次分别败在证据与事实，不能彼此补偿。safe-a 和 safe-b 都过门，前者质量更高，按本例权重胜出。

第一轮 safe-a 的 $0.000900 = (100 × 3 + 20 × 15 + 100 + 200) / 1,000,000，依次包括输入、输出、重试和人工升级。逐次明细在报告行的 trials 中，保留 raw_response 和失败原因；汇总表不会打印整份原始载荷。以上不是任何真实模型的 benchmark 或报价。

🎯 速查卡：Phase 2 一页复习

【L17】解码概念 ≠ 通用 API 字段；Claude Messages API 2026-10-21 版不传 temperature / top_p / top_k
【L18】tiktoken 对匹配 OpenAI 编码计数；Claude 用 count_tokens + usage
【L19】统计错误使幻觉产生，评估可能鼓励猜测；一致不证明正确
【L20】推理能力 / Adaptive Thinking / effort 是三层；档位按模型核对，display ≠ 计费开关
【L21】Base/Instruct 是行为与训练倾向；SFT、RLHF、DPO 路线不同
       直接文档输入 ≠ RAG；API 无状态 ≠ 应用不能保存记忆
【L22】榜单属于模型 + scaffold + 工具 + 预算
       开发集调参、隔离测试集验收；开放权重 ≠ 必须自托管

任务目标

用上面的报告完成课末练习。先判断每个反例为什么失败，再用同一份 fixture 验证，避免把稳定性或自评分误当事实。

操作清单

  1. 核对两个 adapter 是否保留响应、证据、失败原因和同一任务的不同 repeat ID。
  2. 在报告中定位稳定但数值错误、证据不足与接口失败三类反例。
  3. 用本页 usage 与费率手算一次费用，再与程序核对重试和升级。
  4. 只保留不合格候选重跑决策，说明为什么不会选出模型。

通过标准

  • 符号和小数点不被丢弃；原始响应供复核，事实和证据不读取 provider 自评分。
  • 重复证据只计一次；逐次联合过门；至少两次成功响应才评估一致性。
  • 每次及汇总成本可按同一份输入复算；报告保留不合格候选和失败数量。
  • 自检只输出 L24 ACCEPTED；全不合格时报告明确不选择。
课末参考验收（纯标准库；复用上方脚本）

def check_report():
    rows = build_report()
    by_name = {row["name"]: row for row in rows}
    assert len(rows) == 5
    for row in rows:
        items = [item for item, _, _ in row["trials"]]
        assert {item.case_id for item in items} == {CASE}
        assert {item.fixture for item in items} == {FIXTURE}
        assert len(items) == len({item.repeat_id for item in items}) == 2

    assert parse_amount(" -3.14 ") == TRUTH == parse_amount("-3.140")
    assert parse_amount("+3.14") == Decimal("3.14") != TRUTH
    assert parse_amount("-314") == Decimal("-314") != TRUTH
    assert parse_amount("3.14.") is None and parse_amount("-3.14 USD") is None
    first, factual, coverage = by_name["safe-a"]["trials"][0]
    assert first.raw_answer == " -3.14 " and first.evidence_ids == (*BOTH, "rule-cap")
    raw = SAMPLES["safe-a"][1][0][1]
    assert first.raw_response == raw and first.raw_response is not raw
    assert factual and coverage == 1.0 and first.cost_usd == Decimal("0.000900")

    wrong = by_name["stable-wrong"]
    assert wrong["consistency"] == "stable" and wrong["fact_errors"] == wrong["checked"] == 2
    assert all(
        item.raw_response["claimed_factual"] == 1.0 and not factual and coverage == 1.0
        for item, factual, coverage in wrong["trials"]
    )
    compensating = by_name["compensating"]
    assert compensating["consistency"] == "varies"
    assert compensating["trials"][0][0].raw_response["claimed_evidence"] == 1.0
    assert [(factual, coverage) for _, factual, coverage in compensating["trials"]] == [
        (True, 0.5), (False, 1.0),
    ]
    failed = by_name["failed-candidate"]
    assert failed["failures"] == ["provider timeout"] and failed["consistency"] == "n/a"
    assert [item.ok for item, _, _ in failed["trials"]] == [True, False]

    assert [row["cost_usd"] for row in rows] == list(map(Decimal, (
        "0.001600", "0.000900", "0.000720", "0.001000", "0.000600",
    )))
    assert [row["name"] for row in rows if passes(row)] == ["safe-a", "safe-b"]
    assert decide(rows)["name"] == "safe-a"
    rendered = render_report(rows).splitlines()
    assert len(rendered) == 7 and rendered[-1] == "selected: safe-a"
    assert "stable-wrong | 2 | stable | 2/2 | 100% | 98.5 | 0.000720 | FAIL | 0" in rendered
    rejected = [row for row in rows if not passes(row)]
    assert render_report(rejected).endswith("selected: none qualified")


if __name__ == "__main__" and sys.argv[1:] != ["--report"]:
    check_report()
    print("L24 ACCEPTED")

失败诊断：符号、小数断言失败先检查归一化和 Decimal 解析；稳定错误候选过门表示将一致性或自报分数当成真值；证据不足、超时或互补的两轮过门则检查逐次联合条件；成本差异请逐项核对 usage、重试和升级；无合格结果仍出现赢家说明门槛没有先于排名。

  • 选型评的是模型 + adapter + scaffold + 工具 + 预算在你的场景中的表现，不是脱离配置找“最强模型”
  • 每家 API 各用自己的计数方式与 usage；完整成本还要计重试、人工升级等开销
  • 用 adapter 统一业务观察、保留原始响应；稳定性不代替独立事实和证据核验
  • 记录每次运行与失败原因；先逐次过硬门，再在合格集合内归一化和排名
  • 本课固定数据只验证评测流程，不代表真实厂商用量、价格或模型能力
