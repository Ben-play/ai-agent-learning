类型提示系统

给代码标注类型 — Agent 的工具签名、状态、配置，靠它才严谨可查

💡 为什么这课重要？

类型提示是"写给人和工具看的契约"。标注清楚后，IDE 能自动补全、mypy 能在运行前抓出类型 bug，队友一眼看懂参数该传什么。

更关键的是：下一课 Pydantic、以及 L11 的 @tool，都读取你的类型注解来生成工具 Schema。类型标不准，Schema 就不准，LLM 就会传错参。这一课打好类型基础。

※ 泛型 Generic/TypeVar、结构化子类型 Protocol 属进阶，放到 Phase 5（Agent 状态管理）需要时再深讲，本课聚焦最常用的部分。

学习目标

完成本课后，你将能够：

  • 给变量、参数、返回值加基本类型标注
  • 用 Optional 表达"可能为 None"
  • 用 Union 表达"多种类型之一"
  • 用 Literal 约束成有限的取值（如模型名）
  • 用 Callable 标注函数参数，用类型别名简化复杂类型，并跑 mypy

1. 基本标注

def build_prompt(role: str, max_tokens: int = 100) -> str:
    return f"[{role}] limit={max_tokens}"

name: str = "search"
temperature: float = 0.7
tools: list[str] = ["search", "calc"]           # 3.9+ 可直接用内置泛型
config: dict[str, int] = {"max": 5}

注意：类型提示不影响运行——Python 不会因为你传错类型而报错（它只是"提示"）。真正来抓错的是 mypy 这类静态检查工具，以及 IDE 的实时提示。要运行时强制校验，得用 Pydantic（下一课）。

💡 面试常见问题：

"类型提示会在运行时强制类型吗？"

答：不会。它是给静态检查器（mypy）和 IDE 看的元信息，运行时不校验、传错类型也照跑。要运行时校验用 Pydantic。

2. Optional：可能是 None

from typing import Optional

def find_system_prompt(role: str) -> Optional[str]:
    # 返回 str 或 None
    return "你是助手" if role == "system" else None

# Optional[str] 完全等价于 Union[str, None]
result = find_system_prompt("user")   # 可能是 None，用前要判断
if result is not None:
    print(result.upper())

Optional[X] 就是"X 或 None"。Agent 里大量字段可能缺失（工具可能没返回、配置可能没设），用 Optional 明确标出来，提醒调用方"记得判空"。

Q Optional[str] 等价于下面哪个？
Optional[X] 是 Union[X, None] 的简写，表示"值可能是 X，也可能是 None"。它不代表"参数可省略"（那是默认值的事），只表示类型里包含 None。用它提醒调用方判空。

3. Union & Literal

Union：多种类型之一

from typing import Union

def to_text(x: Union[str, bytes]) -> str:
    return x.decode() if isinstance(x, bytes) else x

# 3.10+ 也可写成 str | bytes（更简洁）
def size(x: str | list) -> int:
    return len(x)

Literal：只能是这几个值

from typing import Literal

Role = Literal["system", "user", "assistant"]      # 只能是这三个
Model = Literal["gpt-5", "claude", "gemini"]

def send(role: Role, model: Model) -> None:
    ...

send("user", "claude")     # ✅
send("admin", "claude")    # ❌ mypy 报错：'admin' 不在允许值里
🔑 Agent 开发关联：

Literal 特别适合 Agent 里的"枚举型"参数：消息角色、模型名、工具动作类型、finish_reason。把合法值写进类型，拼错立刻被 mypy 抓到，也让 LLM 工具 Schema 能列出"这个参数只能取这几个值"。

4. Callable & 类型别名 & mypy

Callable：把函数当参数

from typing import Callable

# Callable[[参数类型...], 返回类型]
def apply(fn: Callable[[int], int], x: int) -> int:
    return fn(x)

apply(lambda v: v + 1, 41)     # 42

# Agent 场景：工具就是"接收 dict、返回 dict"的可调用体
ToolFn = Callable[[dict], dict]

类型别名：给复杂类型起名

from typing import TypeAlias

# 一长串类型写多遍很啰嗦，起个别名
Messages: TypeAlias = list[dict[str, str]]

def run(history: Messages) -> Messages:
    return history + [{"role": "assistant", "content": "ok"}]

mypy：把类型错误挡在运行前

# 安装：pip install mypy
# 检查：mypy your_file.py
# 它会报出"传了 str 给需要 int 的参数""可能为 None 却没判空"等问题
Q Literal["a", "b"] 类型的作用是？
Literal 把类型收窄到指定的几个具体值（这里只能是 "a" 或 "b"）。传别的值 mypy 会报错。用于 role、模型名、动作类型等"枚举型"参数，比裸 str 严谨得多。

知识图谱

基本标注 → 参数/返回/变量；不影响运行(只是提示)
├── list[str] / dict[str, int]（3.9+ 内置泛型）
└── 运行时不校验 → 要校验用 Pydantic(L14)

Optional[X] = Union[X, None] → 可能为 None，提醒判空
Union[A, B] / A | B(3.10+) → 多种类型之一
Literal["x","y"] → 只能取这几个值（role/模型名/动作）
Callable[[参数], 返回] → 函数作参数（工具 = ToolFn）
TypeAlias → 给复杂类型起名

mypy → 静态检查，把类型错误挡在运行前
（Generic/TypeVar/Protocol 进阶 → Phase 5）

实战练习

练习：为 Agent 数据加类型

给一段 Agent 相关的代码补上准确的类型注解，用上 Optional / Union / Literal / Callable。先自己写，再看答案。

任务清单

  1. Role：用 Literal 定义为 system/user/assistant
  2. make_message(role, content)：role 用 Role，返回 dict[str, str]
  3. get_tool(name)：按名字查工具，可能查不到 → 返回 Optional[Callable[[dict], dict]]
  4. truncate(x, n)：x 是 str | list，返回同类型的前 n 个
  5. （可选）装 mypy 跑一遍，把报错改干净
💡 点击查看参考答案 
from typing import Optional, Literal, Callable

Role = Literal["system", "user", "assistant"]
ToolFn = Callable[[dict], dict]

def make_message(role: Role, content: str) -> dict[str, str]:
    return {"role": role, "content": content}

_TOOLS: dict[str, ToolFn] = {
    "echo": lambda args: args,
}

def get_tool(name: str) -> Optional[ToolFn]:
    return _TOOLS.get(name)          # 查不到就是 None

def truncate(x: str | list, n: int) -> str | list:
    return x[:n]


msg = make_message("user", "你好")
print(msg)                           # {'role': 'user', 'content': '你好'}

tool = get_tool("echo")
if tool is not None:                 # Optional → 必须判空
    print(tool({"q": "x"}))          # {'q': 'x'}

print(truncate("hello", 3))          # hel
print(truncate([1, 2, 3, 4], 2))     # [1, 2]

面试常见问题

Q1：Python 类型提示在运行时生效吗？

答：不生效。它是给 mypy/IDE 的静态元信息，运行时不校验、传错类型也照跑。要运行时校验用 Pydantic。

Q2：Optional[str] 是什么意思？和"参数可省略"一样吗？

答：它等于 Union[str, None]，表示值可能是 str 或 None。和"参数可省略"（那由默认值决定）不是一回事。

Q3：Literal 有什么用？

答：把类型收窄到指定的几个具体值，适合枚举型参数（role、模型名、动作类型）。传非法值 mypy 会报错，比裸 str 严谨。

Q4：怎么标注"接收函数作参数"？

答：用 Callable[[参数类型...], 返回类型]。例如工具函数是 Callable[[dict], dict]。装饰器、回调、策略注入都会用到。

总结

  • 类型提示是给人/工具看的契约，运行时不强制（要校验用 Pydantic）
  • Optional[X] = Union[X, None]，标出"可能为 None"
  • Union[A,B] / A|B（3.10+）表达多种类型之一
  • Literal 把取值收窄到几个具体值（role/模型名/动作）
  • Callable[[参数],返回] 标注函数参数；TypeAlias 给复杂类型起名
  • 用 mypy 把类型错误挡在运行前；Generic/Protocol 留到 Phase 5
