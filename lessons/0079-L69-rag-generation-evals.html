第七阶段 · 数据与 RAG55分钟

RAG 生成评测

冻结证据包，分开核对出处、支持、正确性与拒答

为什么这课重要？

一个答复说「保留七天」，数值正确，却附上已经替换的旧版本。另一个答复引用完整、版本也对，但拿保留期段落证明过期后自动处理。两者都不合格。还有一种答复，明白告诉用户过期处理缺证据；如果证据包本来就没覆盖它，这是正确的克制，不能当作模型不会答。L68 留下逐行检索记录，本课再把生成部分隔离出来，定位应该修改的环节。

  • 固定证据包，用带人工标签的小样本逐条评估；验证准确引文与正确断言互不替代。
  • 区分证据没给够、生成没有正确用证据、以及两边同时有问题；按缺口进行部分答复或拒答。

1. 给同一次实验固定输入和评判标准

评生成时冻结问题、已授权的租户及用户、证据包的顺序、完整引文与当前资料快照，换生成配置才有可比性。先用固定的、完整的金标证据包跑一遍，看看生成器在资料齐全时是否仍写错；再用真实检索返回的证据包跑一遍，观察整条链路。每组比较内部不换包，不因为答复说得像真的就回库补材料给它记分。课程用手写的候选答复代替模型，便于每次只变化一个字段；这测的是评判契约而不是实际模型表现。

把问题拆成可评判的事实，例如保留期的值是「7 天」、过期处理是「重新发起导出」。金标准答案记录当前业务事实；支持标签另外指定哪个引文表达了哪个事实与值，两类标注不从答复复制。对每条断言独立检查：出处精确，当前授权库按租户、文档编号、版本和定位查到整段，逐字等于引文；包内出现，完整引文确实送到本轮；断言正确，事实和值符合答案标签；引文支持，已验证的包内原文确实支持这条断言。找到真实原文不是支持，支持也不等于业务事实正确，例如可读旧培训稿逐字写了错误数值。练习为简化只允许整片、精确匹配；实际短引文要另订字符范围和规范化规则，不能用模糊定位冒充精确核验。

看到的结果独立失败项交接给谁
答「7 天」，引文定位写成不存在的 §9断言正确，出处及包内核对失败查生成器的结构化引用或展示映射
引文是保留期原文，却用来证明过期处理出处和包内核对通过，但引文不支持断言查断言与证据的对应关系
过期处理证据未给到，只回答已知的保留期并明确缺口答复合格；检索没命中可读金标是检索缺口，命中却装不进是打包缺口分别查 L68 的事实覆盖与 L65 的打包预算
给足两问的证据，仍把过期处理标为缺口不当拒答：漏掉已有支持的事实查生成器使用上下文的逻辑

2. 拒的是证据缺口，不是整批问题

对每个事实，若固定证据包没有可核验且支持正确值的材料，就不输出该断言。部分有证据就给部分答复，明确列出缺失项；都无证据时才整体拒答。本课不允许一边承认缺证，一边输出无依据的值，也不把库中存在但没送进包里的材料当依据。若检索覆盖不足且生成还硬猜，两个环节都记失败。授权是上游硬门：组包前范围、版本或出处不通过，就不能把该包交给生成器。答复本身附上的旧引用则是下游验收失败。评分器只把无效材料视为没有支持，不能从一个高分推断未发生越权。假如证据互相冲突，产品还应定义权威性、时效和转人工规则；本地支持标签仅说明哪句话表达了什么，不能自动裁决冲突。

先用少量手工标注行校验判分器：正控、错误版、错误定位、改过的引文、准确但不支持、来源有误但逐字引用、缺证仍猜、缺证正确拒答。每行保留预期与实际轴，而不是只追求整体通过率。开放问答里语义等价会超出固定值比较；如果另用模型评委，只给它确定性规则不能解决的语义项，先用人工金标做盲测，报告各类分歧（特别是错引、缺证与拒答），并固定评委版本和评分表。在涉及授权或精确出处时，评委不能覆盖程序失败；未校准或版本变化时，回到人工，不把评委的分数当上线证据。本课没有评委调用，不输出真实模型质量结论。

决策卡：先冻结证据，再改生成；先验硬条件，再评语义

适用：同一个 RAG 问答版本要做回归，或只看最终错误无法定位原因。边界：固定标签这里只适用于少量可枚举事实，开放文本须增加人工覆盖。

误判：看答案顺眼就通过

同时换检索与生成，评委也没校准，无法解释缺证或错引从哪来。

选择：按轴保留失败行

固定包评生成；另看真实检索覆盖。先核对授权、精确引用与包，再核对每项事实和拒答。

代价：人工标签和快照需要维护；收益是同一错误可以稳定复现，并能把修复派给对应环节。

  1. 分别准备完整、部分和空证据包；在每包内固定问题与材料。
  2. 每个负例只改一个字段，对照结构检查、正确性和支持度；保存失败样本而非只保存总分。

复查顺序：先排越权；再问证据是否完整，最后看生成是否用准了证据。资料齐全仍错时，不先换排序器。

Q 值正确，库里也能找到该精确引文，但这轮没有把它送进证据包，应怎样记录？
资料库校验、独立金标与实际证据包是三份不同输入，任一通过都不能替代另外两项。

from dataclasses import replace
import runpy

if not __debug__:
    raise RuntimeError("run without -O")
root = "code/phase7-data-rag/rag-lab/"
lab = runpy.run_path(root + "lab.py")
a = runpy.run_path(root + "assessment/checks.py")
Claim, Answer, Citation = (a[name] for name in ("Claim", "Answer", "Citation"))
mei = a["Scope"]("support", "mei")
truth = {"retention": "7 天", "renewal": "重新发起导出"}
policy_key, ops_key = ("EXPORT-POLICY", 1, "§1"), ("EXPORT-OPS", 1, "§2")
support = frozenset({
    Claim("retention", "7 天", Citation("support", policy_key, "导出文件生成后保留 7 天。")),
    Claim("renewal", "重新发起导出", Citation("support", ops_key, "导出文件过期后，需重新发起导出。")),
})
with lab["open_demo"]() as db:
    policy = a["cite"](mei, db.source("support", "mei", policy_key))
    ops = a["cite"](mei, db.source("support", "mei", ops_key))
    retention, renewal = Claim("retention", "7 天", policy), Claim("renewal", "重新发起导出", ops)
    gaps = frozenset({"renewal"})
    packet = (policy,)
    partial = Answer("partial", (retention,), gaps)

    def grade(answer, evidence=packet):
        return a["grade_generation"](db, mei, evidence, answer, truth, support)

    passed = grade(partial)
    assert passed.accepted and passed.expected_gaps == gaps
    assert passed.claims == (a["ClaimGrade"](True, True, True, True),)
    for wrong in (
        replace(policy, key=("EXPORT-POLICY", 2, "§1")),
        replace(policy, key=("EXPORT-POLICY", 1, "§9")),
        replace(policy, quote="导出文件保留 7 天。"),
    ):
        bad = grade(replace(partial, claims=(replace(retention, citation=wrong),)))
        assert bad.claims == (a["ClaimGrade"](False, False, True, False),) and not bad.accepted
    misplaced = grade(Answer("answer", (retention, replace(renewal, citation=policy))))
    assert misplaced.claims[1] == a["ClaimGrade"](True, True, True, False)
    assert not misplaced.gaps_ok and not misplaced.accepted
    full = (policy, ops)
    assert grade(Answer("answer", (retention, renewal)), full).accepted
    needless = grade(partial, full)
    assert needless.expected_gaps == frozenset() and not needless.accepted
print("L69 ACCEPTED")

from dataclasses import replace
import runpy

if not __debug__:
    raise RuntimeError("run without -O")
root = "code/phase7-data-rag/rag-lab/"
lab = runpy.run_path(root + "lab.py")
a = runpy.run_path(root + "assessment/checks.py")
Claim, Answer, Grade, Citation = (a[name] for name in ("Claim", "Answer", "ClaimGrade", "Citation"))
lin = a["Scope"]("support", "lin")
truth = {"schedule": "02:00"}
with lab["open_demo"]() as db:
    old = db.source("support", "lin", ("SYNC-POLICY", 1, "§1"))
    official = replace(old, version=2, locator="§4")
    sample = replace(official, locator="§5", text="训练样张写作：同步任务每天 03:00 运行。")
    db.replace_document("support", old.doc_id, 2, (official, sample))
    policy = a["cite"](lin, db.source("support", "lin", ("EXPORT-POLICY", 1, "§1")))
    fact = Claim("schedule", "02:00", a["cite"](lin, official))
    wrong = Claim("schedule", "03:00", a["cite"](lin, sample))
    support = frozenset({
        Claim("schedule", "02:00", Citation("support", ("SYNC-POLICY", 2, "§4"), "同步任务每天 02:00 运行。")),
        Claim("schedule", "03:00", Citation("support", ("SYNC-POLICY", 2, "§5"),
                                            "训练样张写作：同步任务每天 03:00 运行。")),
    })
    packet_a, packet_b = (a["cite"](lin, sample), policy), (policy,)

    def grade(packet, answer):
        return a["grade_generation"](db, lin, packet, answer, truth, support)

    for claim, expected in ((wrong, Grade(True, True, False, True)),
                            (fact, Grade(True, False, True, False)),
                            (replace(fact, citation=policy), Grade(True, True, True, False))):
        result = grade(packet_a, Answer("answer", (claim,)))
        assert result.claims == (expected,) and not result.accepted
    refuse = Answer("refuse", gaps=frozenset({"schedule"}))
    assert grade(packet_a, refuse).accepted and grade(packet_b, refuse).accepted
    guess = grade(packet_b, Answer("answer", (replace(fact, citation=None),)))
    assert guess.claims == (Grade(False, False, True, False),) and not guess.gaps_ok
    assert not guess.accepted

面试自查

每题先指出哪一层证据足够，再说明最小对照。

Q1检索没找到过期政策，客服只答保留期并说明缺资料，算生成失败吗？

参考回答：按实际包不是生成失败。查该事实的允许金标；若有而没找到，是检索漏项。另给同样问题完整金标包，验证生成能用它答齐。

追问：如果完整包下仍只答保留期呢？

答题要点：这次是生成不当拒答或遗漏；保持包不变改生成边界再测。

Q2数字和原文都对，段落编号已移动，能否只查文档编号便通过？

参考回答：不能。核对当前得到授权的精确版本、定位、引文，并与实际包对照；数字正确只通过了事实轴。

追问：为什么不把库里找到的新编号自动填成原答复的引文？

答题要点：那会改动测试对象；只能另作明确的引用修复，再对新证据包和新答复重新验收。

Q3客服逐字引用旧培训稿，给了一个不符合现行制度的时间，怎么标？

参考回答：若那段训练材料在固定包里且当前可查，出处和文本支持可通过，但业务正确性失败。这表明来源筛选或冲突处理仍须改进。

追问：两条有效证据真的互相冲突时，应否选排名高的？

答题要点：不能把排名当权威，查适用范围、时效与负责人；无法裁决就保留冲突或转人工。

Q4新评委给九成高分，能用它替换人工标签上线吗？

参考回答：总分没说明它是否漏错引、漏错猜或处罚正确拒答。先用独立人工标注集盲测并分项报告，冻结评委版本、评分表和样本，再决定能辅助哪些语义项。

追问：它对开放题更灵活，可否把授权失败改为通过？

答题要点：不可以。权限和精确核验是确定性发布门槛，评委只提供校准后的辅助信号。
