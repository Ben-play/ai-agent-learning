L01 · 类型提示基础

类型提示是 Python 进阶的第一步，也是 Pydantic、Function Calling、mypy 的基础。

为什么 Agent 开发必须学类型提示？

在 Agent 开发中，类型提示不是"可选的美化"，而是核心基础设施：

  • Pydantic 依赖类型提示来验证数据 — 没有类型提示，Pydantic 无法工作
  • LLM Function Calling 的参数 Schema 从类型提示自动生成
  • mypy 能在运行前发现 bug — Agent 系统的 bug 调试成本极高
  • IDE 智能提示让你写代码快 3 倍

基本语法

类型提示用 : 标注变量类型，用 -> 标注函数返回值：

# 变量类型提示
name: str = "Alice"
age: int = 25
scores: list[float] = [9.5, 8.0, 7.5]

# 函数类型提示
def greet(name: str) -> str:
    return f"Hello, {name}!"

# 没有返回值用 None
def log(message: str) -> None:
    print(message)

类型用法示例

Optional：可能为 None 的值

Agent 开发中非常常见——LLM 可能不返回某个字段，工具调用可能失败：

from typing import Optional

# Optional[str] 等价于 str | None
def find_user(user_id: int) -> Optional[str]:
    if user_id == 1:
        return "Alice"
    return None  # 找不到用户

# Python 3.10+ 可以用 str | None
def find_user(user_id: int) -> str | None:
    ...
关键理解：Optional[str] 不是"可选参数"的意思！它是 str | None 的简写，表示"这个值要么是字符串，要么是 None"。可选参数用默认值表示：def f(name: str = "default")。

Union：多种类型之一

当一个值可能是多种类型时使用：

from typing import Union

# Union[str, int] 表示可以是 str 或 int
def process(value: Union[str, int]) -> str:
    return str(value)

# Python 3.10+ 语法
def process(value: str | int) -> str:
    return str(value)

集合类型的进阶标注

from typing import Any

# 列表元素类型
messages: list[dict[str, Any]] = [
    {"role": "user", "content": "hello"},
    {"role": "assistant", "content": "hi"},
]

# 字典的键值类型
scores: dict[str, float] = {"math": 95.0, "english": 88.5}

# 嵌套类型
matrix: list[list[int]] = [[1, 2], [3, 4]]
config: dict[str, list[str]] = {"tags": ["ai", "agent"]}

在 Agent 开发中的实际应用

看一个真实的 Agent 工具定义——类型提示让 LLM 知道每个参数的类型和含义：

from typing import Optional

def search_web(
    query: str,
    max_results: int = 5,
    language: Optional[str] = None,
) -> list[dict[str, str]]:
    """搜索网页并返回结果列表。

    Args:
        query: 搜索关键词
        max_results: 最大返回结果数
        language: 语言过滤，如 "zh"、"en"

    Returns:
        包含 title, url, snippet 的字典列表
    """
    # ... 实现搜索逻辑
    return [{"title": "...", "url": "...", "snippet": "..."}]

这个函数的类型提示告诉 Agent 框架：

  • query 是字符串（必填）
  • max_results 是整数（默认 5）
  • language 是可选字符串
  • 返回值是字典列表

Agent 框架（如 Pydantic AI、LangChain）会自动把这些类型提示转换为 LLM 的 Function Calling Schema。

Q2: list[dict[str, Any]] 表示什么？

动手练习

练习：为 Agent 工具函数添加类型提示

下面的函数缺少类型提示，请补全：

def get_weather(city, unit="celsius", days=3):
    """获取天气预报"""
    forecasts = []
    for i in range(days):
        forecasts.append({
            "day": i + 1,
            "temp": 25 + i,
            "unit": unit,
        })
    return forecasts

要求：

  • 所有参数都要有类型提示
  • 返回值要有类型提示
  • unit 只能是 "celsius" 或 "fahrenheit"（提示：用 Literal）
点击查看参考答案 
from typing import Literal

def get_weather(
    city: str,
    unit: Literal["celsius", "fahrenheit"] = "celsius",
    days: int = 3,
) -> list[dict[str, str | int]]:
    """获取天气预报"""
    forecasts: list[dict[str, str | int]] = []
    for i in range(days):
        forecasts.append({
            "day": i + 1,
            "temp": 25 + i,
            "unit": unit,
        })
    return forecasts
