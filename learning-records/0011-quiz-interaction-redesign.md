# Quiz 交互重设计（考卷批改式，v2）

应用户要求，把课程 Quiz 从「点选即锁 + 答案直接在问题下方冒出」重做成更友好的**两步式「考卷批改」交互**。纯改 `assets/quiz.js`（行为 + 注入样式），**不改任何课程 HTML**，因此自动作用于所有含 Quiz 的课程页（当前 L02–L05 共 11 题）。

## 交互变化（解决"不友好"的核心）
- **选择 ≠ 判分**：点选项只是"选中"（可反复改），不再立即锁定/变色。这消除了旧版"手滑点错就锁死"的最大痛点。
- **两步确认**：出现「核对答案」按钮，点了才批改。
- **批改揭晓**：选中项盖 ✓/✗ 图章、暖色调对错反馈（正确=森林绿，错误用暖赭 #B4530E 而非刺眼正红）；答错时温和地把正确项也标出来。
- **解析批注**：判分后「解析」带标签+左侧色条**滑入**（max-height 过渡），而非突兀 display:block。
- **鼓励式结果语** + **「再试一次」**：答错不设死路，可重来。
- 细节：选项加 A/B/C/D 字母标记、卷角暗纹、hover 抬升、`prefers-reduced-motion` 降级、`radiogroup/radio` + `aria-checked` + `aria-live` 无障碍、方向键切换选项。全部走设计 token，深浅色皆可。

## 验证
- `node --check` 通过；跨课程确认所有选项均为纯文本（innerHTML 包裹安全）；quiz.js 在 style.css 之后加载（注入样式覆盖旧 `.quiz-option` 规则）。
- 用自建 DOM shim（含 innerHTML 解析 + className）**跑通完整逻辑**：选择不判分、两步确认、切换选择、判分标正确、✓ 图章、答错揭晓正确项、再试重置——全部断言通过。

**Why:** 用户觉得旧版"点击答案直接在问题下方展开"不友好。
**How to apply:** 后续新课的 Quiz 沿用同一 DOM 契约（.quiz > .quiz-options > button[data-answer] > .quiz-explanation）即可自动获得新交互，无需额外代码。参见 [[0010-l05-lesson-authored]]。

## v3 迭代（用户二次反馈）
用户要求「去掉核对答案这个部分 + 配色再优化」。改动：
- **去掉两步确认**：移除「核对答案」按钮，点选项即判分（更直接）；手滑补救改由「再试一次」承担。
- **配色升级为编辑风克制表达**：不再整块填色，改为「柔和底色 + 左侧强调条 + 字母徽章 A/B/C/D 变成 ✓/✗ 徽章」；非答案项淡出(opacity .42 + 降饱和)让正确答案自然聚焦；错误用暖赭 #B4530E，正确用课程 --success 绿的 12% 柔色；hover 暖琥珀 + 字母徽章填色 + 右侧「→」提示。全程走 token，深浅色皆宜。
- 验证：node --check + DOM 模拟跑通（点击即判分、✓/✗ 徽章、答错揭晓正确项、再试恢复字母、二次点击锁定）。
