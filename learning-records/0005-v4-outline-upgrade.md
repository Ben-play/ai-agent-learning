# 大纲 v4 升级：2026 技术趋势整合

基于 2026 年 6 月的行业调研，对学习大纲进行了全面升级（v3 → v4）。

## 关键发现

1. **Agent Harness 成为 2026 主导架构** — "Harness Engineering" 正在取代 "Prompt Engineering" 成为核心技能
2. **Context Engineering 新兴** — 设计和管理 Agent 上下文窗口的工程实践，2026 年 Agent 工程师的核心能力
3. **MCP 已标准化** — 被称为"AI 的 USB-C"，Google 官方有开发者指南
4. **A2A + ANP 协议** — Agent 间通信和网络协议标准化
5. **Agentic RAG** — RAG 从管道进化为 Agent 控制的智能检索
6. **Agent Memory 独立** — 从子话题升级为专门的工程领域（Mem0 等框架）
7. **120+ Agentic AI 工具** — 跨 11 类别的成熟生态

## 主要变更

- Phase 5: 新增 Context Window 管理策略
- Phase 6: 重命名为「Prompt & Context Engineering」
