单 Agent Harness · 验收速查

适用于 Phase 5 的「证据问答＋本地工单草稿」。这是一份复盘清单，不是生产准入证明，也不另计课号。

决定要不要加 Agent

  • 固定规则已经满足业务契约，先用函数；步骤需要独立检查时用确定性流程。
  • 下一步确需按观测选择时，才比较单 Agent。L45 的固定路径对照只验证练习差异，不证明模型性能。
  • 把预算检查放在调用之前；区分成功、依赖失败、预算耗尽。工具的类型、参数合法和执行授权是三道不同检查。见 L46 / L47。

遇到失败时看什么

场景需要观察
压缩旧交互调用与结果整组闭合，原文和来源可回查；重组后重新计数。L48
更正或删除偏好在同一租户和用户范围检查现值、来源、到期与删除。L49
审批未通过或草稿改版禁止执行；应用核对身份、实际动作和确切版本，不认模型话术。L50
进程重启同一待审任务恢复，不能凭恢复成功执行；审批前草稿表为空。L51
本地提交后丢响应原操作 ID 读回同一结果，且实际只有一次写入。外部结果未知先核对。L52

交接

保留输入、可判定结果、必要轨迹及未验证项。迁移框架时复跑业务断言，不硬编码合法实现的顺序。见 L54；有疑问可带最小离线用例提问。
