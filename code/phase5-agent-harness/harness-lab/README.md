# Phase 5：证据问答＋受控工单草稿

这是 [L54 阶段验收](../../../lessons/0062-L54-harness-acceptance.html) 的离线项目，复用 [Phase 4](../../phase4-prompt-context/README.md) 的合成知识库、逐字引用校验和草稿模板。需要完整课程仓库和 Python 3.11+；仅用标准库，不需安装依赖或配置凭据。

## 运行

从仓库根进入项目目录：

```bash
cd code/phase5-agent-harness/harness-lab
python main.py
python -m unittest discover -s tests -v
```

演示成功时只打印一行：

```text
PHASE5 HARNESS OK baseline=failed/1 dynamic=complete/2 budget=exhausted/1 draft=saved/replayed
```

课程代码也可以从可信的课程路径加载 `main.py`，调用不接收参数、不打印的 `run_acceptance()`。它返回可序列化的字典，包含三条问答路径的状态和调度次数、通过校验的引用 ID，以及草稿各用例的状态、写入尝试次数和最终已提交行数。入口不过问凭据，SQLite 只使用演示或测试创建的临时目录；演示退出后文件会清理。

## 验收什么

- **只读循环与固定基线**：两条路径都从「导出文件有效期？」开始。固定路径只查一次，未命中时停止；动态脚本仅在收到 `needs_evidence` 后建议改写成「导出文件保留多久？」。执行器只接受具名的证据问答任务与非空问题。`pending` 表示仍在处理，`complete` 需要有效的 Phase 4 答案，`failed` 表示请求或证据路径未通过；需要再查而预算不足则为 `exhausted`。预算耗尽后不再调度。次数指 Phase 4 问答入口调用数（即使没命中也计一次），不是模型或适配器调用数。问答路径不写库。
- **两步工单流程**：先将待审批快照写入 SQLite 检查点，此时保存草稿表仍为空；应用再用明确的模拟人工决定恢复。批准必须匹配租户、操作者、任务、`save_local_draft` 动作、版本和正文快照摘要（覆盖标题、正文和引用 ID）。拒绝会结束该任务；更换待审批版本后，旧批准不能保存新草稿；仅同一请求的重放可取回原保存结果。草稿以外的动作没有执行入口。
- **写入尝试与已提交行数**：`draft.write_attempts` 记录各用例在执行 `saved_drafts` 插入前由宿主观察到的次数，不数 `resume` 调用、检查点更新或提交。暂存待审（`pending`）、缺审批（`missing_review`）、审批作用域不匹配（`unauthorized`）、拒绝（`denied`）和旧版绑定（`changed`）各为零；有效批准后模拟丢应答（`commit`）为一，重放（`replay`）新增零次。`draft.saved_count` 则是重放后从 SQLite 查询到的一条已提交草稿；尝试不保证提交，零行也不证明零尝试。
- **提交后丢应答**：业务草稿和检查点上的稳定操作 ID 在同一 SQLite 事务提交。模拟丢应答发生在提交之后；关闭连接，再用新连接复查并重放，返回原操作 ID 和原草稿，记录数仍为一。无法核对已保存的结果时停止，不重新写入。

## 验证范围

比较的是合成数据上的脚本路径，不是提示或在线模型的效果、费用或延迟。加载 Phase 4 只使用相对于 `main.py` 的固定仓库路径，不接受待执行的外部路径。模拟身份和审批来自可信的本地宿主代码，不是登录系统或安全沙箱；没有真实工单创建、提交、队列、远程操作、任意命令或外部调用。写入观察只覆盖这个教学项目的本地草稿插入；同一事务中的本地幂等不代表远程副作用恰好一次。

本项目只验证**重开 SQLite 连接**，不是退出进程再启动；跨进程操作见 [L51](../../../lessons/0059-L51-approval-checkpoint-resume.html) 的独立练习。记忆的作用域、纠正和删除见 [L49](../../../lessons/0057-L49-memory-lifecycle.html)；本项目不实现记忆库或上下文压缩。
