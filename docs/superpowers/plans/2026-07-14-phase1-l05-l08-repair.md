- [ ] **Step 3: 补全 global 示例**

### Task 3: 修复 L07 对象实例化基础与 frozen 语义

**Files:**
- Modify: `lessons/0011-L07-classes-and-dataclass.html`

**Interfaces:**
- Consumes: L05 函数、L06 作用域。
- Produces: 类/对象/实例化/`__init__` 的最小心智模型；准确的浅层 frozen 语义。

- [ ] **Step 1: 复现 frozen 边界**

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class ToolCall:
    name: str
    args: dict

tc = ToolCall("search", {"q": "python"})
tc.args["q"] = "changed"
assert tc.args["q"] == "changed"
try:
    hash(tc)
except TypeError:
    pass
else:
    raise AssertionError("dict field should make hash fail")
```

Expected: 内部 dict 可修改；`hash(tc)` 抛 `TypeError`。

- [ ] **Step 2: 在类入口补对象与实例化**

明确：类是模板；`Agent("bot")` 是调用类创建实例；`a` 指向实例；`__init__` 在实例创建后负责初始化字段；`self` 是当前实例。将“方法第一个参数永远是 self”改为“实例方法惯例为 self；classmethod 为 cls；staticmethod 无隐式 self/cls”。

- [ ] **Step 3: 收敛类属性说明**

将“所有实例共享”改为“默认从类上读取；实例可用同名属性遮蔽”。点明可变类属性才是共享状态陷阱，避免让读者误以为 `a.default_model = ...` 会修改全部实例。

- [ ] **Step 4: 修正 frozen 文案和示例**

说明 frozen 阻止字段重新绑定，不会递归冻结字段内部对象；含 list/dict 字段时内部仍可能修改，也通常不可 hash。若要可 hash 的 ToolCall 示例，改为不可变字段：

```python
@dataclass(frozen=True)
class ToolCallKey:
    name: str
    args_json: str
```

不再声称 frozen 自动线程安全。思考题 Q2 同步：frozen AgentState 的 `self.step += 1` 会失败，但 `self.messages.append` 对内部 list 本身仍可能成功；真正深度不可变需要不可变字段类型。

- [ ] **Step 5: 运行 L07 示例和练习**

验证实例/类属性遮蔽、三种方法、dataclass repr/eq/default_factory、frozen 重绑定失败、内部 dict 可变、不可变键可 hash、AgentState 正常更新。
